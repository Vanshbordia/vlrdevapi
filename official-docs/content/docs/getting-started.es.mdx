VLRdevAPI es una biblioteca de Python para consultar datos de esports de Valorant desde [VLR.gg](https://www.vlr.gg/). Se encarga de las peticiones HTTP, el raspado de HTML y la normalización de datos para que puedas trabajar con objetos tipados de Python en lugar de texto plano sin formato.

## Visión General de la Arquitectura

La biblioteca ofrece dos formas principales de acceder a los datos:

- **Acceso a nivel de módulo** - un cliente por defecto con inicialización diferida (lazy) para consultas rápidas en una sola línea
- **`VLRClient` explícito** - te proporciona control total sobre configuraciones, tiempos de espera (timeouts) y ciclo de vida de los recursos

Ambos enfoques ofrecen los mismos seis espacios de nombres (namespaces):

| Espacio de nombres | Descripción |
|---|---|
| `matches` | Listados de partidos próximos, en vivo y finalizados |
| `team` | Información de equipos, plantillas (rosters), estadísticas, partidos y posiciones |
| `player` | Perfiles de jugadores, agentes, equipos e historial de partidos |
| `event` | Información de torneos, fases, tablas de clasificación, equipos y partidos |
| `series` | Información de series, VODs, estadísticas de jugadores y economía |
| `news` | Listados de noticias y artículos completos |

## Requisitos Previos

- **Python 3.11 o superior** - Comprueba tu versión actual con `python --version`

## Instalación

```bash
uv add vlrdevapi
```

O con pip:

```bash
pip install vlrdevapi
```

## Patrones de Uso

<Steps>
  <Step>

  ### Acceso a nivel de módulo

  La forma más sencilla de comenzar. La biblioteca inicializa un cliente por defecto en la primera llamada.

```python
import vlrdevapi

matches = vlrdevapi.matches.upcoming()
for match in matches.matches[:5]:
    t1 = match.team1.name if match.team1 else "Por definir"
    t2 = match.team2.name if match.team2 else "Por definir"
    print(f"{t1} vs {t2}")
```
  </Step>

  <Step>

  ### Cliente explícito con gestor de contexto

  Utilízalo cuando requieras configuración personalizada o desees gestionar explícitamente el cierre de conexiones.

  ```python
  from vlrdevapi import VLRClient

  with VLRClient() as client:
      page = client.matches.upcoming()
      for match in page.matches[:5]:
          t1 = match.team1.name if match.team1 else "Por definir"
          t2 = match.team2.name if match.team2 else "Por definir"
          print(f"{t1} vs {t2}")
  ```
  </Step>

  <Step>

  ### Acceso encadenado (Curried)

  Pasa un ID una sola vez y encadena llamadas de métodos sucesivas.

  ```python
  import vlrdevapi

  team = vlrdevapi.team(2593)
  info = team.info()
  roster = team.roster()
  print(f"{info.name} tiene {len(roster.players)} jugadores")
  ```
  </Step>
</Steps>

## Referencia de Métodos

Cada espacio de nombres incluye métodos especializados para cada tipo de dato:

- **`matches.upcoming()`** / **`matches.live()`** / **`matches.completed()`** - listados de partidos
- **`team(id)`** - datos específicos de equipos (plantilla, estadísticas, partidos, posiciones)
- **`player(id)`** - datos específicos de jugadores (perfil, agentes, equipos, historial)
- **`event(id)`** - datos específicos de torneos (información, fases, clasificación, equipos)
- **`series(id)`** - datos específicos de series (información, VODs, estadísticas, economía)
- **`news(page)`** / **`news.article(article_id)`** - listados de noticias y artículos completos

## Exportación para Ciencia de Datos y Formatos Tabulares

Todos los modelos de respuesta en VLRdevAPI incorporan métodos directos de exportación tabular:

```python
import vlrdevapi

# Obtén estadísticas de jugadores y conviértelas a pandas o polars
players = vlrdevapi.series(754737).players()

# Exporta directamente a DataFrame de pandas
df = players.to_df()
print(f"Exportados {len(df)} registros a DataFrame")

# O a un DataFrame nativo de Polars
pl_df = players.to_polars()

# Guarda en disco como CSV, Excel, Parquet o JSON
players.to_csv("players_stats.csv")
players.to_excel("players_stats.xlsx")
players.to_parquet("players_stats.parquet")
players.to_json("players_stats.json")
```

## Servidor MCP (Model Context Protocol)

Conecta Claude Desktop, Cursor o agentes de IA autónomos a datos de Valorant en vivo mediante el servidor MCP integrado:

```bash
# Ejecutar mediante CLI
vlrdevapi-mcp

# O ejecutar directamente sin instalación con uvx
uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```

Descubre más detalles en la guía [Servidor MCP](/docs/mcp/).
