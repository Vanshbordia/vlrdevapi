VLRdevAPI 是一个 Python 库，为从 [VLR.gg](https://www.vlr.gg/) 获取无畏契约 (Valorant) 电竞数据提供了干净、类型安全的接口。它负责网页爬取、解析和数据规范化，让您可以专注于构建自己的应用程序。

## 功能特性

- **比赛数据** - 获取带有详细统计数据的即将进行和已结束的比赛
- **选手资料** - 查询选手统计、特工使用情况和表现指标
- **战队信息** - 获取战队阵容、排名和历史交锋记录
- **赛事报道** - 浏览锦标赛、赛程安排和积分榜
- **新闻与文章** - 浏览新闻列表并获取 Markdown 格式的完整文章
- **类型安全** - 完善的类型提示 (Type Hints)，提供更佳的 IDE 支持并减少运行时错误
- **并发请求** - 多阶段端点通过线程池并行抓取页面

## 快速上手

```bash
# 使用 uv (推荐)
uv add vlrdevapi

# 或使用 pip
pip install vlrdevapi
```

```python
# doc-check: skip
import vlrdevapi

page = vlrdevapi.matches.upcoming()
for match in page.matches[:3]:
    team1 = match.team1.name if match.team1 else "待定"
    team2 = match.team2.name if match.team2 else "待定"
    print(f"{team1} vs {team2} | {match.event}")
```
