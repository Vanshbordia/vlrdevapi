VLRdevAPI es una biblioteca de Python que proporciona una interfaz limpia y con tipado seguro para obtener datos de esports de Valorant desde [VLR.gg](https://www.vlr.gg/). Gestiona el raspado (scraping), análisis y normalización de datos para que puedas concentrarte en desarrollar tu aplicación.

## Características

- **Datos de Partidos** - Obtén partidos próximos y finalizados con estadísticas detalladas
- **Perfiles de Jugadores** - Accede a estadísticas de jugadores, agentes más usados y métricas de rendimiento
- **Información de Equipos** - Consulta plantillas (rosters), clasificaciones e historial de partidos
- **Cobertura de Torneos** - Explora torneos, calendarios y resultados
- **Noticias y Artículos** - Revisa la lista de noticias y lee artículos completos en formato Markdown
- **Tipado Seguro** - Sugerencias de tipos completas (type hints) para un mejor soporte en el IDE y menos errores en tiempo de ejecución
- **Peticiones Concurrentes** - Los endpoints multietapa obtienen sus páginas en paralelo mediante un grupo de subprocesos

## Inicio Rápido

```bash
# con uv (recomendado)
uv add vlrdevapi

# o con pip
pip install vlrdevapi
```

```python
# doc-check: skip
import vlrdevapi

page = vlrdevapi.matches.upcoming()
for match in page.matches[:3]:
    team1 = match.team1.name if match.team1 else "Por definir"
    team2 = match.team2.name if match.team2 else "Por definir"
    print(f"{team1} vs {team2} | {match.event}")
```
