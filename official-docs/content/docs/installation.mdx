## Requirements

- Python 3.11 or newer
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

## Install from PyPI

Install with [uv](https://docs.astral.sh/uv/):

```bash
uv add vlrdevapi
```

Or with pip:

```bash
pip install vlrdevapi
```

## Optional Dependency Extras

VLRdevAPI provides modular extras so you only install the dependencies your project requires:

```bash
# Data science exports
pip install "vlrdevapi[pandas]"     # pandas.DataFrame (.to_df())
pip install "vlrdevapi[polars]"     # polars.DataFrame (.to_polars())
pip install "vlrdevapi[excel]"      # Excel .xlsx (.to_excel())
pip install "vlrdevapi[parquet]"    # Apache Parquet (.to_parquet())

# Model Context Protocol server
pip install "vlrdevapi[mcp]"        # vlrdevapi-mcp CLI for Claude & Cursor

# Install all optional extras
pip install "vlrdevapi[all]"
```

## Install from Source

Clone the repository and install with uv:

```bash
git clone https://github.com/vanshbordia/vlrdevapi.git
cd vlrdevapi
uv sync
```

Or with pip in editable mode:

```bash
git clone https://github.com/vanshbordia/vlrdevapi.git
cd vlrdevapi
pip install -e .
```

## Verify Installation

```bash
python -c "import vlrdevapi; m = vlrdevapi.matches.upcoming(); print(f'VLRdevAPI {len(m.matches)} upcoming matches loaded')"
```
