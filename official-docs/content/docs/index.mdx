VLRdevAPI is a Python library that provides a clean, type-safe interface for fetching Valorant esports data from [VLR.gg](https://www.vlr.gg/). It handles scraping, parsing, and data normalization so you can focus on building your application.

## Features

- **Match Data** - Fetch upcoming and completed matches with detailed statistics
- **Player Profiles** - Access player stats, agent usage, and performance metrics
- **Team Information** - Get team rosters, rankings, and match history
- **Event Coverage** - Browse tournaments, schedules, and results
- **News & Articles** - Browse the news listing and fetch full articles with Markdown content
- **Type-Safe** - Full type hints for better IDE support and fewer runtime errors
- **Concurrent Fetching** - Multi-stage endpoints fetch their pages in parallel with a thread pool

## Quickstart

```bash
# with uv (recommended)
uv add vlrdevapi

# or with pip
pip install vlrdevapi
```

```python
# doc-check: skip
import vlrdevapi

page = vlrdevapi.matches.upcoming()
for match in page.matches[:3]:
    team1 = match.team1.name if match.team1 else "TBD"
    team2 = match.team2.name if match.team2 else "TBD"
    print(f"{team1} vs {team2} | {match.event}")
```
