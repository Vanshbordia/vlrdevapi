VLRdevAPI é uma biblioteca Python que oferece uma interface limpa e fortemente tipada para extrair dados de esports do Valorant diretamente do [VLR.gg](https://www.vlr.gg/). Ela cuida da raspagem (scraping), análise e normalização dos dados para que você possa focar no desenvolvimento do seu aplicativo.

## Recursos

- **Dados de Partidas** - Obtenha partidas futuras e concluídas com estatísticas detalhadas
- **Perfis de Jogadores** - Acesse estatísticas de jogadores, uso de agentes e métricas de desempenho
- **Informações de Times** - Consulte escalações (rosters), rankings e histórico de partidas
- **Cobertura de Eventos** - Navegue por torneios, cronogramas e tabelas de classificação
- **Notícias e Artigos** - Acesse a lista de notícias e leia artigos completos formatados em Markdown
- **Tipagem Segura** - Dicas de tipo completas (type hints) para melhor suporte na IDE e menos erros em tempo de execução
- **Busca Concorrente** - Endpoints de múltiplos estágios buscam suas páginas em paralelo usando pool de threads

## Início Rápido

```bash
# com uv (recomendado)
uv add vlrdevapi

# ou com pip
pip install vlrdevapi
```

```python
# doc-check: skip
import vlrdevapi

page = vlrdevapi.matches.upcoming()
for match in page.matches[:3]:
    team1 = match.team1.name if match.team1 else "A Definir"
    team2 = match.team2.name if match.team2 else "A Definir"
    print(f"{team1} vs {team2} | {match.event}")
```
