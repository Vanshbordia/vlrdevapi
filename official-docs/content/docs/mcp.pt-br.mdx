Conecte qualquer assistente de código com IA ou agente autônomo diretamente aos dados de esports em tempo real do Valorant sem configuração complexa, sem hospedagem e sem necessidade de chaves de API (API keys).

```bash
# Claude Code CLI (comando único)
claude mcp add vlrdevapi -- uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```

Ou adicione o JSON de configuração no seu cliente:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

## Configuração em 10 Segundos por Cliente

### Claude Code CLI

Execute este comando único no seu terminal:

```bash
claude mcp add vlrdevapi -- uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```

O Claude Code instalará o servidor sob demanda, registrará as 40 ferramentas e as disponibilizará imediatamente na sua sessão.

### Claude Desktop

Abra seu arquivo de configuração:
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
- **Linux**: `~/.config/Claude/claude_desktop_config.json`

Adicione `vlrdevapi` sob a chave `mcpServers`:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

Reinicie o Claude Desktop. O ícone de martelo exibirá mais de 40 ferramentas de Valorant disponíveis.

### Cursor IDE

1. Abra **Cursor Settings** &rarr; **Features** &rarr; **MCP Servers**.
2. Clique em **Add New MCP Server**.
3. Nome: `vlrdevapi`, Tipo: `command`, Comando: `uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp`.

Ou adicione diretamente em `.cursor/mcp.json` no seu workspace:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

### Windsurf / Codeium

Adicione em `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

### Editor Zed

No arquivo `settings.json` do Zed:

```json
{
  "context_servers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }

```

## Agentes de IA Autônomos (OpenCode, DeepSeek, Codex, Grok, etc.)

Para agentes autônomos ou frameworks LLM customizados, basta configurar o executor de ferramentas para rodar:

```bash
uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```

### Prompt Pronto para Inserir no seu Agente

Você pode colar esta instrução de sistema em qualquer agente:

> **Integração de Dados de Esports do Valorant:**
> Você tem acesso ao servidor VLRdevAPI Model Context Protocol (MCP). Execute-o via stdio padrão usando `uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp`.
> - Use ferramentas compostas como `get_match_full_context(series_id)` e `get_team_overview(team_id)` para consultas abrangentes.
> - Use `matches_live()` e `matches_upcoming()` para calendários de jogos.
> - Use `player_agents(player_id)` e `get_player_career_summary(player_id)` para análise de jogadores.
> - Nenhuma chave de API ou serviço externo é necessário.

## O que Você Pode Perguntar à sua IA

Após conectar, sua IA pode responder diretamente a perguntas em linguagem natural usando dados em tempo real do VLR.gg:

* *"Quem está jogando ao vivo agora no VCT?"* &rarr; chama `matches_live()`

* *"Compare FNATIC e LOUD no histórico direto"* &rarr; chama `compare_teams(team_id_1=2593, team_id_2=6961)`

## Ferramentas Compostas de Alto Nível (Ideais para IA)

O servidor fornece 9 ferramentas compostas desenhadas especificamente para raciocínio em múltiplos passos de IA. Em vez de fazer 5 requisições separadas, seu agente obtém um dossiê completo em uma única chamada:

| Ferramenta | Parâmetros | O que retorna |
|:---|:---|:---|
| `get_match_full_context` | `series_id` | Visão geral da partida, estatísticas dos jogadores e links de transmissões/VODs. |
| `get_team_overview` | `team_id` | Perfil do time, elenco ativo, resultados recentes, próximos confrontos e premiações. |
| `compare_teams` | `team_id_1`, `team_id_2` | Comparação lado a lado de elencos, rankings, premiações e fase recente. |
| `get_player_career_summary` | `player_id` | Biografia do jogador, times atuais, estatísticas por agente e histórico de colocações. |
| `get_h2h_matchup` | `team_id_1`, `team_id_2` | Histórico completo de confrontos diretos entre dois times. |
| `get_tournament_dossier` | `event_id` | Visão completa do torneio combinando times participantes, fases e chaveamento. |
| `get_live_and_upcoming_schedule` | `limit` | Partidas ao vivo combinadas com os próximos jogos agendados. |
| `get_news_digest` | `limit`, `include_top_article_body` | Resumo das últimas notícias com opção de corpo completo em Markdown. |
| `series_map_summary` | `series_id`, `game_id` | Análise detalhada de mapa único com economia, eventos de replay e notas de jogadores. |

## Catálogo Granular Completo (40 Ferramentas)

Além das ferramentas compostas, todos os endpoints do VLRdevAPI estão disponíveis individualmente:

* **Matches**: `matches_upcoming`, `matches_live`, `matches_completed`
* **Series**: `series_info`, `series_players`, `series_rounds`, `series_performance`, `series_economy`, `series_replay`, `series_vods`, `series_map_summary`
* **Teams**: `team_info`, `team_roster`, `team_stats`, `team_completed_matches`, `team_upcoming_matches`, `team_transactions`, `team_placements`
* **Players**: `player_info`, `player_teams`, `player_agents`, `player_matches`, `player_profile`, `player_placements`
* **Events**: `events_list`, `event_info`, `event_stages`, `event_teams`, `event_matches`, `event_standings`
* **News**: `news_list`, `news_article`

## Por que a Configuração Zero Funciona

1. **Sem Chaves de API**: Os dados do VLR.gg não exigem token de autenticação ou cadastro de desenvolvedor.
2. **Isolamento com `uvx`**: O `uvx` baixa o `vlrdevapi[mcp]` para um cache temporário, executa o servidor e mantém seu ambiente Python limpo.
3. **Tratamento Seguro de Erros**: Falhas de domínio (`NotFoundError`, `ValidationError`) retornam payloads estruturados em JSON, evitando travamentos no chat com a IA.
4. **Economia de Tokens**: Usa serialização otimizada para JSON e dicionários do VLRdevAPI, prevenindo o esgotamento da janela de contexto do modelo.
