```bash
claude mcp add vlrdevapi -- uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```


## 10-Second Setup by Client

### Claude Code CLI

Run this single command in your terminal:

```bash
claude mcp add vlrdevapi -- uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```

Claude Code will automatically install the server on demand, register all 41 tools, and make them available in your session.

### Claude Desktop

Open your configuration file:
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
- **Linux**: `~/.config/Claude/claude_desktop_config.json`

Add `vlrdevapi` under `mcpServers`:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

Restart Claude Desktop. You will see the hammer icon showing 41 available Valorant tools.

### Cursor IDE

1. Open **Cursor Settings** &rarr; **Features** &rarr; **MCP Servers**.
2. Click **Add New MCP Server**.
3. Name: `vlrdevapi`, Type: `command`, Command: `uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp`.

Or add it directly to `.cursor/mcp.json` in your workspace:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

## High-Level Composite Tools (Best for AI)

The server provides 9 composite tools designed specifically for multi-step AI reasoning. Instead of making 5 separate requests, your agent gets a complete dossier in one call:

| Tool | Parameters | What it returns |
|:---|:---|:---|
| `get_match_full_context` | `series_id` | Match overview, player statistics, and streams/VODs. |
| `get_team_overview` | `team_id` | Team profile, active roster, recent results, upcoming fixtures, and placements. |
| `compare_teams` | `team_id_1`, `team_id_2` | Side-by-side comparison of rosters, rankings, earnings, and recent form. |
| `get_player_career_summary` | `player_id` | Player biography, current teams, agent pool ratings, and placements. |
| `get_h2h_matchup` | `team_id_1`, `team_id_2` | Complete historical head-to-head match records between two teams. |
| `get_tournament_dossier` | `event_id` | Tournament overview combining participating teams, stages, and standings. |
| `get_live_and_upcoming_schedule` | `limit` | Live matches ticker combined with upcoming schedules. |
| `get_news_digest` | `limit`, `include_top_article_body` | Latest esports news digest with optional full Markdown article body. |
| `series_map_summary` | `series_id`, `game_id` | Single-map breakdown combining map economy, replay events, and player ratings. |

## Complete Granular Tool Catalog (41 Tools)

In addition to composite tools, every single VLRdevAPI endpoint is exposed as an MCP tool:

* **Matches**: `matches_upcoming`, `matches_live`, `matches_completed`
* **Series**: `series_info`, `series_players`, `series_rounds`, `series_performance`, `series_economy`, `series_replay`, `series_vods`, `series_map_summary`
* **Teams**: `team_info`, `team_roster`, `team_stats`, `team_completed_matches`, `team_upcoming_matches`, `team_transactions`, `team_placements`
* **Players**: `player_info`, `player_teams`, `player_agents`, `player_matches`, `player_profile`, `player_placements`
* **Events**: `events_list`, `event_info`, `event_stages`, `event_teams`, `event_matches`, `event_standings`
* **News**: `news_list`, `news_article`

## Why Zero Setup Works

1. **No API Keys**: VLR.gg data requires no authentication token or developer account.
2. **`uvx` Isolation**: `uvx` downloads `vlrdevapi[mcp]` to a temporary cache, executes the server, and keeps your system Python clean.
3. **Graceful Error Trapping**: Domain errors (`NotFoundError`, `ValidationError`) return structured JSON error payloads, preventing AI chat crashes.
4. **Token-Efficient Serialization**: Uses VLRdevAPI's optimized dictionary and JSON serialization to avoid bloating the model's context window.
