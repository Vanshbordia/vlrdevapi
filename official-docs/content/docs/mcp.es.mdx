Conecta cualquier asistente de programación con IA o agente autónomo directamente a datos de esports de Valorant en tiempo real, sin configuraciones complejas, sin servidores externos y sin necesidad de claves de API.

```bash
# Claude Code CLI (comando único)
claude mcp add vlrdevapi -- uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```

O añade el bloque JSON directamente en la configuración de tu cliente:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

## Configuración en 10 Segundos por Cliente

### Claude Code CLI

Ejecuta este único comando en tu terminal:

```bash
claude mcp add vlrdevapi -- uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp
```

Claude Code descargará e instalará el servidor automáticamente bajo demanda, registrará las 40 herramientas y las pondrá a tu disposición en la sesión activa.

### Claude Desktop

Abre tu archivo de configuración:
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
- **Linux**: `~/.config/Claude/claude_desktop_config.json`

Añade `vlrdevapi` bajo `mcpServers`:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

Reinicia Claude Desktop. El icono de martillo mostrará más de 40 herramientas de Valorant listas para usarse.

### Cursor IDE

1. Ve a **Cursor Settings** &rarr; **Features** &rarr; **MCP Servers**.
2. Pulsa en **Add New MCP Server**.
3. Nombre: `vlrdevapi`, Tipo: `command`, Comando: `uvx --from "vlrdevapi[mcp]" vlrdevapi-mcp`.

O añádelo en `.cursor/mcp.json` en tu espacio de trabajo:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }
}
```

### Windsurf / Codeium

Añade en `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]
    }
  }

```

### Editor Zed

En el archivo `settings.json` de Zed:

```json
    "vlrdevapi": {
      "command": "uvx",
      "args": ["--from", "vlrdevapi[mcp]", "vlrdevapi-mcp"]

  }

```

## Herramientas Compuestas de Alto Nivel (Ideales para IA)

El servidor ofrece 9 herramientas compuestas diseñadas específicamente para el razonamiento en varios pasos. En vez de realizar 5 consultas independientes, tu agente recibe un informe completo en una sola llamada:

| Herramienta | Parámetros | Qué devuelve |
|:---|:---|:---|
| `get_match_full_context` | `series_id` | Resumen del partido, estadísticas de jugadores y enlaces a retransmisiones/VODs. |
| `get_team_overview` | `team_id` | Perfil del equipo, plantilla activa, resultados recientes, calendario y premios. |
| `compare_teams` | `team_id_1`, `team_id_2` | Comparativa lado a lado de plantillas, clasificaciones, ingresos y racha actual. |
| `get_player_career_summary` | `player_id` | Biografía del jugador, equipos actuales, rendimiento por agente y resultados. |
| `get_h2h_matchup` | `team_id_1`, `team_id_2` | Historial completo de enfrentamientos directos entre dos equipos. |
| `get_tournament_dossier` | `event_id` | Información completa del torneo: equipos participantes, fases y clasificación. |
| `get_live_and_upcoming_schedule` | `limit` | Partidos en vivo combinados con la programación de próximos encuentros. |
| `get_news_digest` | `limit`, `include_top_article_body` | Titulares y resumen de noticias de esports con cuerpo completo opcional en Markdown. |
| `series_map_summary` | `series_id`, `game_id` | Desglose exhaustivo de un mapa con economía, eventos y valoraciones individuales. |

## Catálogo Granular Completo (40 Herramientas)

Además de las herramientas compuestas, cada endpoint de VLRdevAPI está expuesto de forma individual:

* **Matches**: `matches_upcoming`, `matches_live`, `matches_completed`
* **Series**: `series_info`, `series_players`, `series_rounds`, `series_performance`, `series_economy`, `series_replay`, `series_vods`, `series_map_summary`
* **Teams**: `team_info`, `team_roster`, `team_stats`, `team_completed_matches`, `team_upcoming_matches`, `team_transactions`, `team_placements`
* **Players**: `player_info`, `player_teams`, `player_agents`, `player_matches`, `player_profile`, `player_placements`
* **Events**: `events_list`, `event_info`, `event_stages`, `event_teams`, `event_matches`, `event_standings`
* **News**: `news_list`, `news_article`

## Por Qué Funciona Sin Configuración

1. **Sin Claves de API**: Los datos de VLR.gg no requieren token ni registro.
2. **Aislamiento con `uvx`**: `uvx` gestiona la descarga en una caché temporal aislada, manteniendo limpio el entorno Python de tu sistema.
3. **Manejo Seguro de Excepciones**: Los errores de dominio (`NotFoundError`, `ValidationError`) retornan estructuras JSON ordenadas, evitando caídas inesperadas en el chat con la IA.
4. **Optimización de Tokens**: Aprovecha la serialización compacta en diccionario y JSON de VLRdevAPI para optimizar la ventana de contexto del modelo.
