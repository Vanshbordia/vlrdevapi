---
title: Colocações do Jogador (Player Placements)
description: "Obtenha as colocações em torneios e premiações em dinheiro conquistadas pelo jogador no vlr.gg."
---

`player.placements(player_id)` retorna o histórico de colocações em eventos e o total de premiações em dinheiro acumuladas a partir do card de Event Placements na página do jogador no vlr.gg.

## Assinatura

```python
player.placements(player_id: int) -> PlayerPlacements
```

Com acesso curried:

```python
vlrdevapi.player(player_id).placements() -> PlayerPlacements
```

## Exemplos

### Listar todas as colocações

```python
import vlrdevapi

placements = vlrdevapi.player.placements(player_id=46051)

print(
    f"{placements.total_winnings_currency}"
    f"{placements.total_winnings:,} em premiações totais"
)
for entry in placements.placements:
    prize = (
        f"{entry.prize_currency}{entry.prize_amount:,}"
        if entry.prize_amount is not None
        else "sem premiação"
    )
    print(
        f"{entry.year} | {entry.event_name} | "
        f"{entry.stage} - {entry.placement} | {entry.team_name} | {prize}"
    )
```

### Agrupar colocações por torneio

```python
from collections import defaultdict
import vlrdevapi

result = vlrdevapi.player.placements(player_id=11225)
events = defaultdict(list)

for entry in result.placements:
    events[(entry.event_id, entry.event_name)].append(entry)

for (event_id, event_name), rows in events.items():
    print(f"{event_name} ({event_id})")
    for row in rows:
        print(f"  {row.stage}: {row.placement} ({row.team_name})")
```

### Acesso curried

```python
import vlrdevapi

player = vlrdevapi.player(46051)
placements = player.placements()

for entry in placements.placements:
    if entry.prize_amount:
        print(f"{entry.event_name}: {entry.prize_currency}{entry.prize_amount:,}")
```
