## Exemplos

### Consulta básica do jogador

Obtenha o nick, nome real, país e perfis em redes sociais.

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=438)
print(f"{info.name} ({info.real_name})")
print(f"País: {info.country}")
print(f"X: {info.x_handle}")
print(f"Twitch: {info.twitch_handle}")
```

### Consultar outros nomes (aliases)

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=438)
aliases = info.aliases if info.aliases else ["(nenhum)"]
print(f"{info.name} também foi conhecido como: {', '.join(aliases)}")
```

### Consultar premiação total

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=46051)
if info.total_winnings is not None:
    print(f"{info.name}: {info.total_winnings_currency}{info.total_winnings:,}")
else:
    print(f"{info.name}: premiação não informada")
```

### Acesso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
info = player.info()
print(f"{info.name} - {info.country_code.upper()}")
```
