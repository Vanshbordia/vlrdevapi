`player.teams(player_id)` 返回该选手在 vlr.gg 上的当前战队及历史效力战队列表。

## 函数签名

```python
player.teams(player_id: int) -> PlayerTeams
```

<TypeTable type={{

## 示例

### 查询当前与过往战队

```python
import vlrdevapi

teams = vlrdevapi.player.teams(player_id=438)

print("当前效力战队:")
for t in teams.current_teams:
    print(f"  {t.name} (自 {t.joined_date})")

print("历史效力战队:")
for t in teams.past_teams:
    end = t.left_date or t.inactive_date or "至今"
    print(f"  {t.name} ({t.joined_date} - {end})")
```

### 构建职业生涯战队时间线

```python
import vlrdevapi
from datetime import datetime, timezone

teams = vlrdevapi.player.teams(player_id=438)
all_teams = teams.current_teams + teams.past_teams
for t in sorted(all_teams, key=lambda x: x.joined_date or datetime(1, 1, 1, tzinfo=timezone.utc)):
    print(f"{t.joined_date}: 加入 {t.name}")
    if t.left_date:
        print(f"{t.left_date}: 离开 {t.name}")
```

### 柯里化链式访问

```python
import vlrdevapi

player = vlrdevapi.player(438)
teams = player.teams()
print(f"当前战队: {[t.name for t in teams.current_teams]}")
```
