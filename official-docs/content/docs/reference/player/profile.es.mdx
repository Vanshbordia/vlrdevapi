`player.profile(player_id)` devuelve un perfil consolidado de un jugador combinando información básica, equipo actual y estadísticas de sus agentes principales.

## Firma

```python
player.profile(player_id: int) -> PlayerProfile
```

## Ejemplos

### Vista completa del perfil

El método `profile` es un atajo muy conveniente que combina datos biográficos, equipo actual y estadísticas de agentes principales en una sola petición.

```python
import vlrdevapi

profile = vlrdevapi.player.profile(player_id=438)
print(f"{profile.name} ({profile.real_name})")
print(f"País: {profile.country}")
team_name = profile.current_team.name if profile.current_team else "(agente libre)"
print(f"Equipo: {team_name}")
print("Agentes principales:")
if profile.top_agents:
    for a in profile.top_agents[:3]:
        print(f"  {a.agent}: rating {a.rating}, KD {a.kd}")
else:
    print("  (sin datos de agentes)")
```

### Resumen de redes sociales

```python
import vlrdevapi

profile = vlrdevapi.player.profile(player_id=438)
print(f"X: {profile.x_handle} ({profile.x_link})")
print(f"Twitch: {profile.twitch_handle} ({profile.twitch_link})")
```

### Acceso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
profile = player.profile()
if profile.top_agents:
    best_agent = max(profile.top_agents, key=lambda a: a.rating or 0)
    print(f"Mejor agente de {profile.name}: {best_agent.agent} ({best_agent.rating} rating)")
