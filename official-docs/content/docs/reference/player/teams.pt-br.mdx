`player.teams(player_id)` retorna as equipes atuais e históricas de um jogador no vlr.gg.

## Assinatura

```python
player.teams(player_id: int) -> PlayerTeams
```

<TypeTable type={{

## Exemplos

### Equipes atuais e passadas

```python
import vlrdevapi

teams = vlrdevapi.player.teams(player_id=438)

print("Equipes atuais:")
for t in teams.current_teams:
    print(f"  {t.name} (desde {t.joined_date})")

print("Equipes anteriores:")
for t in teams.past_teams:
    end = t.left_date or t.inactive_date or "presente"
    print(f"  {t.name} ({t.joined_date} - {end})")
```

### Linha do tempo das equipes

```python
import vlrdevapi
from datetime import datetime, timezone

teams = vlrdevapi.player.teams(player_id=438)
all_teams = teams.current_teams + teams.past_teams
for t in sorted(all_teams, key=lambda x: x.joined_date or datetime(1, 1, 1, tzinfo=timezone.utc)):
    print(f"{t.joined_date}: Entrou em {t.name}")
    if t.left_date:
        print(f"{t.left_date}: Saiu de {t.name}")
```

### Acesso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
teams = player.teams()
print(f"Atualmente em: {[t.name for t in teams.current_teams]}")
```
