`player.profile(player_id)` retorna um perfil consolidado combinando informações cadastrais, equipe atual e estatísticas dos principais agentes.

## Assinatura

```python
player.profile(player_id: int) -> PlayerProfile
```

## Exemplos

### Visão geral completa do perfil

O método `profile` combina dados cadastrais, equipe atual e principais agentes em uma única consulta simplificada.

```python
import vlrdevapi

profile = vlrdevapi.player.profile(player_id=438)
print(f"{profile.name} ({profile.real_name})")
print(f"País: {profile.country}")
team_name = profile.current_team.name if profile.current_team else "(sem equipe)"
print(f"Equipe: {team_name}")
print("Principais agentes:")
if profile.top_agents:
    for a in profile.top_agents[:3]:
        print(f"  {a.agent}: {a.rating} rating, {a.kd} KD")
else:
    print("  (sem dados de agentes)")
```

### Resumo das redes sociais

```python
import vlrdevapi

profile = vlrdevapi.player.profile(player_id=438)
print(f"X: {profile.x_handle} ({profile.x_link})")
print(f"Twitch: {profile.twitch_handle} ({profile.twitch_link})")
```

### Acesso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
profile = player.profile()
if profile.top_agents:
    best_agent = max(profile.top_agents, key=lambda a: a.rating or 0)
    print(f"Melhor agente de {profile.name}: {best_agent.agent} ({best_agent.rating} rating)")
