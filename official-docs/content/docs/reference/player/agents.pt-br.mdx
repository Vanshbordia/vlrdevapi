---
title: Estatísticas por Agente (Player Agents)
description: "Obtenha estatísticas detalhadas de cada agente jogado - rating, ACS, K/D, ADR, KAST e mais ao longo de um período configurável."
---

`player.agents(player_id, timespan)` retorna estatísticas detalhadas de cada agente jogado por um jogador no vlr.gg.

## Assinatura

```python
player.agents(
    player_id: int,
    timespan: Literal["30d", "60d", "90d", "all"] = "all",
) -> AgentStatsPage
```

## Exemplos

### Estatísticas de agentes com período padrão

```python
import vlrdevapi

stats = vlrdevapi.player.agents(player_id=438)
print(f"Período: {stats.timespan}")
if stats.agents:
    for a in stats.agents:
        print(f"{a.agent}: {a.rounds}r | {a.rating} rating | {a.acs} ACS | {a.kd} KD")
else:
    print("Nenhuma estatística de agente disponível para este jogador.")
```

### Filtrar pelos últimos 60 dias

```python
import vlrdevapi

stats = vlrdevapi.player.agents(player_id=438, timespan="60d")
if stats.agents:
    for a in stats.agents:
        rnd = a.rounds or 0
        rat = f"{a.rating:.2f}" if a.rating is not None else "N/A"
        acs = f"{a.acs:.1f}" if a.acs is not None else "N/A"
        kd = f"{a.kd:.2f}" if a.kd is not None else "N/A"
        adr = f"{a.adr:.1f}" if a.adr is not None else "N/A"
        print(f"{a.agent:>8} | {rnd:>3}r | R={rat} | ACS={acs} | K/D={kd} | ADR={adr}")
else:
    print("Nenhum dado encontrado para os últimos 60 dias.")
```

### Identificar o agente mais jogado

```python
import vlrdevapi

stats = vlrdevapi.player.agents(player_id=438, timespan="all")
if stats.agents:
    most_played = max(stats.agents, key=lambda a: a.rounds or 0)
    print(f"Mais jogado: {most_played.agent} ({most_played.rounds} rounds)")
    print(f"Rating: {most_played.rating} | KD: {most_played.kd} | ACS: {most_played.acs}")
else:
    print("Nenhuma estatística de agente disponível para este jogador.")
```

### Acesso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
stats = player.agents(timespan="90d")
if stats.agents:
    for a in stats.agents:
        rnd = a.rounds or 0
        rat = f"{a.rating:.2f}" if a.rating is not None else "N/A"
        print(f"{a.agent}: rating {rat} em {rnd} rounds")
else:
    print("Nenhuma estatística de agente encontrada para este jogador.")
```
