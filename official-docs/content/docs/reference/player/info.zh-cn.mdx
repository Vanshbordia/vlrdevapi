`player.info(player_id)` 返回指定选手在 vlr.gg 上的基础资料。

## 函数签名

```python
player.info(player_id: int) -> PlayerInfo
```

## 示例

### 基础查询选手信息

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=438)
print(f"{info.name} ({info.real_name})")
print(f"国家/地区: {info.country}")
print(f"X 用户名: {info.x_handle}")
print(f"Twitch 用户名: {info.twitch_handle}")
```

### 查看选手曾用名 (Aliases)

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=438)
aliases = info.aliases if info.aliases else ["(无)"]
print(f"{info.name} 的曾用名: {', '.join(aliases)}")
```

### 查询选手总奖金

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=46051)
if info.total_winnings is not None:
    print(f"{info.name}: {info.total_winnings_currency}{info.total_winnings:,}")
else:
    print(f"{info.name}: 暂无奖金数据")
```

### 柯里化链式访问

```python
import vlrdevapi

player = vlrdevapi.player(438)
info = player.info()
print(f"{info.name} - {info.country_code.upper()}")
