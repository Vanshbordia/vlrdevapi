```python
player.profile(player_id: int) -> PlayerProfile

## 示例

### 查看选手完整综合档案

`profile` 方法是一个便捷整合接口，只需一次网络调用即可同时获取资料、当前战队与主力特工。

```python
import vlrdevapi

profile = vlrdevapi.player.profile(player_id=438)
print(f"{profile.name} ({profile.real_name})")
print(f"国家/地区: {profile.country}")
team_name = profile.current_team.name if profile.current_team else "(自由人/无战队)"
print(f"所属战队: {team_name}")
print("主力特工:")
if profile.top_agents:
    for a in profile.top_agents[:3]:
        print(f"  {a.agent}: Rating {a.rating}, KD {a.kd}")
else:
    print("  (暂无特工数据)")
```

### 提取社交平台链接

```python
import vlrdevapi

profile = vlrdevapi.player.profile(player_id=438)
print(f"X: {profile.x_handle} ({profile.x_link})")
print(f"Twitch: {profile.twitch_handle} ({profile.twitch_link})")
```

### 柯里化链式访问

```python
import vlrdevapi

player = vlrdevapi.player(438)
profile = player.profile()
if profile.top_agents:
    best_agent = max(profile.top_agents, key=lambda a: a.rating or 0)
    print(f"{profile.name} 最拿手的特工: {best_agent.agent} (Rating {best_agent.rating})")
