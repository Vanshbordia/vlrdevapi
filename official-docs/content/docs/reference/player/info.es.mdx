`player.info(player_id)` devuelve información básica de un jugador en vlr.gg.

## Firma

```python
player.info(player_id: int) -> PlayerInfo
```

## Ejemplos

### Búsqueda básica de un jugador

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=438)
print(f"{info.name} ({info.real_name})")
print(f"País: {info.country}")
print(f"X: {info.x_handle}")
print(f"Twitch: {info.twitch_handle}")
```

### Consultar alias históricos

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=438)
aliases = info.aliases if info.aliases else ["(ninguno)"]
print(f"{info.name} también ha sido conocido como: {', '.join(aliases)}")
```

### Comprobar ganancias totales

```python
import vlrdevapi

info = vlrdevapi.player.info(player_id=46051)
if info.total_winnings is not None:
    print(f"{info.name}: {info.total_winnings_currency}{info.total_winnings:,}")
else:
    print(f"{info.name}: ganancias no disponibles")
```

### Acceso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
info = player.info()
print(f"{info.name} - {info.country_code.upper()}")
```
