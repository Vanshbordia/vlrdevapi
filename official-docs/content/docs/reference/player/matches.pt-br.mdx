`player.matches(player_id, limit)` retorna o histórico de partidas disputadas por um jogador no vlr.gg.

## Assinatura

```python
player.matches(
    player_id: int,
    limit: int = 20,
) -> PlayerMatches
```

## Exemplos

### Histórico recente de partidas

```python
import vlrdevapi

history = vlrdevapi.player.matches(player_id=438, limit=10)
print(f"Partidas recentes do jogador {history.player_id}:")
if history.matches:
    for m in history:
        result = "VENCEU" if m.result == "win" else "derrota"
        print(f"  {m.team1.name} {m.score1} - {m.score2} {m.team2.name} ({result}) - {m.event}")
else:
    print("  Nenhum histórico de partidas encontrado.")
```

### Análise de vitórias e derrotas

```python
import vlrdevapi

history = vlrdevapi.player.matches(player_id=438, limit=50)
wins = sum(1 for m in history if m.result == "win")
losses = sum(1 for m in history if m.result == "loss")
total = wins + losses
pct = wins / total * 100 if total else 0
print(f"Desempenho: {wins}V - {losses}D ({pct:.0f}% taxa de vitória)")
```

### Filtrar partidas de um torneio específico

```python
import vlrdevapi

history = vlrdevapi.player.matches(player_id=438, limit=100)
champions_matches = [m for m in history if "champions" in m.event.lower()]
if champions_matches:
    for m in champions_matches[:5]:
        print(f"{m.stage} {m.bracket}: {m.team1.name} vs {m.team2.name} ({m.score1}-{m.score2})")
```

### Acesso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
history = player.matches(limit=5)
if history.matches:
    for m in history:
        print(f"{m.date}: {'V' if m.result == 'win' else 'D'} {m.team1.tag} {m.score1}-{m.score2} {m.team2.tag}")
