`player.matches(player_id, limit)` 返回指定选手在 vlr.gg 上的历史比赛记录。

## 函数签名

```python
player.matches(
    player_id: int,
    limit: int = 20,
) -> PlayerMatches
```

## 示例

### 查看近期比赛记录

```python
import vlrdevapi

history = vlrdevapi.player.matches(player_id=438, limit=10)
print(f"选手 {history.player_id} 的近期比赛:")
if history.matches:
    for m in history:
        res = "获胜" if m.result == "win" else "落败"
        print(f"  {m.team1.name} {m.score1} - {m.score2} {m.team2.name} ({res}) - {m.event}")
else:
    print("  未找到比赛历史记录。")
```

### 统计近期比赛胜率

```python
import vlrdevapi

history = vlrdevapi.player.matches(player_id=438, limit=50)
wins = sum(1 for m in history if m.result == "win")
losses = sum(1 for m in history if m.result == "loss")
total = wins + losses
pct = wins / total * 100 if total else 0
print(f"战绩: {wins}胜 - {losses}负 (胜率 {pct:.0f}%)")
```

### 柯里化链式访问

```python
import vlrdevapi

player = vlrdevapi.player(438)
history = player.matches(limit=5)
if history.matches:
    for m in history:
        print(f"{m.date}: {'胜' if m.result == 'win' else '负'} {m.team1.tag} {m.score1}-{m.score2} {m.team2.tag}")
```
