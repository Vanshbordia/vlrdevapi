---
title: Historial de Partidas del Jugador (Player Matches)
description: "Obtén el historial de partidas de un jugador: rivales, marcadores, resultados, contexto del evento y fechas de los encuentros."
---

`player.matches(player_id, limit)` devuelve el historial de partidas disputadas por un jugador en vlr.gg.

## Firma

```python
player.matches(
    player_id: int,
    limit: int = 20,
) -> PlayerMatches
```

## Ejemplos

### Historial reciente de partidas

```python
import vlrdevapi

history = vlrdevapi.player.matches(player_id=438, limit=10)
print(f"Partidas recientes del jugador {history.player_id}:")
if history.matches:
    for m in history:
        result = "VICTORIA" if m.result == "win" else "derrota"
        print(f"  {m.team1.name} {m.score1} - {m.score2} {m.team2.name} ({result}) - {m.event}")
else:
    print("  No se encontró historial de partidas.")
```

### Calcular balance de victorias / derrotas

```python
import vlrdevapi

history = vlrdevapi.player.matches(player_id=438, limit=50)
wins = sum(1 for m in history if m.result == "win")
losses = sum(1 for m in history if m.result == "loss")
total = wins + losses
pct = wins / total * 100 if total else 0
print(f"Registro: {wins}V - {losses}D ({pct:.0f}% porcentaje de victorias)")
```

### Acceso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
history = player.matches(limit=5)
if history.matches:
    for m in history:
        print(f"{m.date}: {'V' if m.result == 'win' else 'D'} {m.team1.tag} {m.score1}-{m.score2} {m.team2.tag}")
```
