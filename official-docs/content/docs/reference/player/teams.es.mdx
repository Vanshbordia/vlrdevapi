title: Equipos del Jugador (Player Teams)

`player.teams(player_id)` devuelve los equipos actuales e históricos de un jugador en vlr.gg.

## Firma

```python
player.teams(player_id: int) -> PlayerTeams
```

## Parámetros

<TypeTable type={{
  "player_id": {

    typeDescription: "Entero positivo",
    required: true,

}} />

## Ejemplos

### Equipos actuales y pasados

```python
import vlrdevapi

teams = vlrdevapi.player.teams(player_id=438)

print("Equipos actuales:")
for t in teams.current_teams:
    print(f"  {t.name} (desde {t.joined_date})")

print("Equipos anteriores:")
for t in teams.past_teams:
    end = t.left_date or t.inactive_date or "presente"
    print(f"  {t.name} ({t.joined_date} - {end})")
```

### Cronología de equipos

```python
import vlrdevapi
from datetime import datetime, timezone

teams = vlrdevapi.player.teams(player_id=438)
all_teams = teams.current_teams + teams.past_teams
for t in sorted(all_teams, key=lambda x: x.joined_date or datetime(1, 1, 1, tzinfo=timezone.utc)):
    print(f"{t.joined_date}: Se unió a {t.name}")
    if t.left_date:
        print(f"{t.left_date}: Salió de {t.name}")
```

### Acceso curried

```python
import vlrdevapi

player = vlrdevapi.player(438)
teams = player.teams()
print(f"Actualmente en: {[t.name for t in teams.current_teams]}")
