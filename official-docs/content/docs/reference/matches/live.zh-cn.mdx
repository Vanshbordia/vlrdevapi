---
title: 实时进行中比赛 (Live Matches)
description: "获取 vlr.gg 上当前正在直播开打的比赛信息，包含队伍即时比分与赛段状态。"
---

`matches.live()` 返回当前在 vlr.gg 上标记为进行中的所有实时比赛对局。

## 方法签名

```python
matches.live() -> LiveMatchesPage
```

## 代码示例

```python
import vlrdevapi

live_page = vlrdevapi.matches.live()
print(f"当前正在进行的对局数: {len(live_page.matches)}")

for match in live_page.matches:
    t1 = match.team1.name if match.team1 else "战队 1"
    t2 = match.team2.name if match.team2 else "战队 2"
    s1 = match.team1.score if match.team1 and match.team1.score is not None else 0
    s2 = match.team2.score if match.team2 and match.team2.score is not None else 0
    print(f"正在直播: {t1} [{s1} - {s2}] {t2} | {match.event}")
```
