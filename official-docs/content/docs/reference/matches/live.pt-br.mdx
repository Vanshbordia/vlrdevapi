`matches.live()` retorna todas as partidas que estão em andamento neste momento no vlr.gg.

## Assinatura

```python
matches.live() -> LiveMatchesPage
```

## Exemplos de Código

```python
import vlrdevapi

live_page = vlrdevapi.matches.live()
print(f"Partidas ao vivo agora: {len(live_page.matches)}")

for match in live_page.matches:
    t1 = match.team1.name if match.team1 else "Time 1"
    t2 = match.team2.name if match.team2 else "Time 2"
    s1 = match.team1.score if match.team1 and match.team1.score is not None else 0
    s2 = match.team2.score if match.team2 and match.team2.score is not None else 0
    print(f"AO VIVO: {t1} [{s1} - {s2}] {t2} | {match.event}")
```
