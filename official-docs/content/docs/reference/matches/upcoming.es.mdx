---
title: Partidos Próximos (Upcoming Matches)
description: "Explora los próximos partidos programados en vlr.gg con soporte para paginación individual y múltiple."
---

`matches.upcoming()` devuelve un listado paginado de partidos futuros en vlr.gg, permitiendo consultar varias páginas consecutivas.

## Firma

```python
matches.upcoming(
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> UpcomingMatchesPage
```

## Ejemplos de Código

```python
import vlrdevapi

page = vlrdevapi.matches.upcoming(page=1)

for match in page.matches[:5]:
    t1 = match.team1.name if match.team1 else "Por definir"
    t2 = match.team2.name if match.team2 else "Por definir"
    print(f"{t1} vs {t2} | {match.event} ({match.stage})")
    print(f"Hora: {match.datetime} (comienza en {match.eta})")
    print(f"URL: https://vlr.gg{match.url}\n")
```
