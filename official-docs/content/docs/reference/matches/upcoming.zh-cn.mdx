description: "浏览 vlr.gg 上即将开打的比赛日程列表，支持单页与跨页自动合并抓取。"
---

`matches.upcoming()` 返回来自 vlr.gg 的近期赛程分页列表，原生支持跨多页自动连续抓取。

## 方法签名

```python
matches.upcoming(
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> UpcomingMatchesPage
```

## 代码示例

```python
import vlrdevapi

page = vlrdevapi.matches.upcoming(page=1)

for match in page.matches[:5]:
    t1 = match.team1.name if match.team1 else "待定"
    t2 = match.team2.name if match.team2 else "待定"
    print(f"{t1} vs {t2} | {match.event} ({match.stage})")
    print(f"开赛时间: {match.datetime} (倒计时: {match.eta})")
    print(f"链接: https://vlr.gg{match.url}\n")
```
