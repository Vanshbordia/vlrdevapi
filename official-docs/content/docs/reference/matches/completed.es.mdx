title: Partidos Finalizados (Completed Matches)
description: "Explora partidos finalizados en vlr.gg con marcadores, información de ganadores y paginación con soporte multipágina."
---

`matches.completed()` devuelve una lista paginada de partidos concluidos en vlr.gg, incluyendo marcadores definitivos e indicación de equipos ganadores.

## Firma

```python
matches.completed(
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> CompletedMatchesPage
```

## Ejemplos de Código

```python
import vlrdevapi

completed_page = vlrdevapi.matches.completed(page=1)

for match in completed_page.matches[:5]:
    t1 = match.team1.name if match.team1 else "TBD"
    t2 = match.team2.name if match.team2 else "TBD"
    s1 = match.team1.score if match.team1 and match.team1.score is not None else 0
    s2 = match.team2.score if match.team2 and match.team2.score is not None else 0
    winner = t1 if match.team1 and match.team1.is_winner else t2
    print(f"{t1} [{s1} - {s2}] {t2} -> Ganador: {winner} ({match.event})")
```
