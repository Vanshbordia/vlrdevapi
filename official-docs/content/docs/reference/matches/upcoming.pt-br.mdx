title: Partidas Futuras (Upcoming Matches)
description: "Consulte partidas futuras agendadas no vlr.gg com suporte a paginação e busca de múltiplas páginas."
---

`matches.upcoming()` retorna uma listagem paginada de partidas agendadas no vlr.gg, com suporte nativo para busca de várias páginas em sequência.

## Assinatura

```python
matches.upcoming(
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> UpcomingMatchesPage
```

## Exemplos de Código

```python
import vlrdevapi

page = vlrdevapi.matches.upcoming(page=1)

for match in page.matches[:5]:
    t1 = match.team1.name if match.team1 else "A Definir"
    t2 = match.team2.name if match.team2 else "A Definir"
    print(f"{t1} vs {t2} | {match.event} ({match.stage})")
    print(f"Horário: {match.datetime} (em {match.eta})")
    print(f"URL: https://vlr.gg{match.url}\n")
```
