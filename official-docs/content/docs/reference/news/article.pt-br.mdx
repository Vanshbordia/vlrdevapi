---
title: Artigo de Notícia (News Article)
description: "Obtenha o conteúdo completo de um artigo de notícia do vlr.gg."
---

`news.article()` busca o conteúdo integral do corpo de um artigo de notícia do vlr.gg. O corpo é retornado tanto como texto puro (`content`) quanto convertido para Markdown (`content_md`), preservando cabeçalhos, listas aninhadas, tabelas, links, código verbatim, ênfases e incorporações de clipes da Twitch. `date` é retornado como um datetime UTC ciente de fuso horário.

Se o ID do artigo não existir no vlr.gg, um erro `NotFoundError` é levantado (o vlr.gg retorna uma página genérica para IDs desconhecidos, que é detectada a partir do conteúdo).

## Assinatura

```python
news.article(
    article_id: int,
) -> NewsArticle
```

## Exemplos

### Buscar um artigo

```python
import vlrdevapi

article = vlrdevapi.news.article(734100)
print(f"{article.title}")
print(f"Por {article.author} em {article.date}")
print(f"Evento: {article.event_name}")
print(article.content)
```

### Ler o artigo formatado em Markdown

```python
import vlrdevapi

article = vlrdevapi.news.article(734100)
print(article.content_md)
```

### Acessar um artigo encontrado na lista de notícias

```python
import vlrdevapi

page = vlrdevapi.news(page=1)
article_id = page.news[0].id
article = vlrdevapi.news.article(article_id)
print(article.title)
```
