`news()` 返回 vlr.gg 网站上分页的新闻资讯列表。

## 函数签名

```python
news(
    page: int = 1,
) -> NewsPage
```

## 示例

### 获取最新新闻

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
print(f"当前页新闻数量: {len(result.news)}")
print(f"是否有下一页: {result.has_next_page}")

for item in result.news:
    print(f"{item.date.date()} | {item.title} | 作者: {item.author}")
```

### 按国家/地区筛选新闻

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
local_news = [n for n in result.news if n.country_name == "China"]
if local_news:
    for n in local_news:
        print(f"{n.title} - {n.author}")
else:
    print("当前页暂无中国相关的新闻。")
```
