`news()` retorna uma listagem paginada de itens de notícias do vlr.gg.

## Assinatura

```python
news(
    page: int = 1,
) -> NewsPage
```

## Exemplos

### Buscar as notícias mais recentes

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
print(f"Notícias nesta página: {len(result.news)}")
print(f"Mais páginas disponíveis: {result.has_next_page}")

for item in result.news:
    print(f"{item.date.date()} | {item.title} | por {item.author}")
```

### Filtrar notícias por país

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
local_news = [n for n in result.news if n.country_name == "Brazil"]
if local_news:
    for n in local_news:
        print(f"{n.title} - {n.author}")
else:
    print("Nenhuma notícia brasileira nesta página no momento.")
```
