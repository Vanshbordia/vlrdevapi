`news()` devuelve una lista paginada de noticias desde vlr.gg.

## Firma

```python
news(
    page: int = 1,
) -> NewsPage
```

## Ejemplos

### Obtener las últimas noticias

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
print(f"Noticias en esta página: {len(result.news)}")
print(f"Más páginas disponibles: {result.has_next_page}")

for item in result.news:
    print(f"{item.date.date()} | {item.title} | por {item.author}")
```

### Filtrar noticias por país

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
local_news = [n for n in result.news if n.country_name == "Spain"]
if local_news:
    for n in local_news:
        print(f"{n.title} - {n.author}")
else:
    print("No hay noticias de España en esta página actualmente.")
```
