---
title: 新闻文章 (News Article)
description: "获取 vlr.gg 网站上单篇新闻文章的完整内容。"
---

`news.article()` 获取 vlr.gg 网站上单篇新闻文章的完整正文内容。正文同时以纯文本格式（`content`）和经过 Markdown 转换的格式（`content_md`）返回，后者完整保留了标题层级、嵌套列表、表格、链接、逐字代码块、文本强调以及 Twitch 剪辑内嵌。`date` 以带时区信息的 UTC datetime 对象返回。

如果文章 ID 在 vlr.gg 上不存在，则会抛出 `NotFoundError`（vlr.gg 会针对不存在的 ID 返回通用错误页面，SDK 会自动从页面内容中识别并抛出异常）。

## 函数签名

```python
news.article(
    article_id: int,
) -> NewsArticle
```

## 示例

### 获取单篇新闻文章

```python
import vlrdevapi

article = vlrdevapi.news.article(734100)
print(f"{article.title}")
print(f"作者: {article.author} | 发布时间: {article.date}")
print(f"关联赛事: {article.event_name}")
print(article.content)
```

### 以 Markdown 格式读取文章内容

```python
import vlrdevapi

article = vlrdevapi.news.article(734100)
print(article.content_md)
```

### 获取新闻列表中文章的详情

```python
import vlrdevapi

page = vlrdevapi.news(page=1)
article_id = page.news[0].id
article = vlrdevapi.news.article(article_id)
print(article.title)
```
