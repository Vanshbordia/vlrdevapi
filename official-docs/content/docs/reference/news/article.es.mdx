---
title: Artículo de Noticias (News Article)
description: "Obtén el contenido completo de un artículo de noticias de vlr.gg."
---

`news.article()` obtiene el contenido completo del cuerpo de un artículo de noticias de vlr.gg. El contenido se devuelve tanto en texto plano (`content`) como en formato Markdown (`content_md`), conservando encabezados, listas anidadas, tablas, enlaces, bloques de código, énfasis e inserciones de clips de Twitch. `date` se devuelve como un datetime UTC con información de zona horaria.

Si el ID del artículo no existe en vlr.gg, se lanza una excepción `NotFoundError` (vlr.gg retorna una página genérica ante IDs desconocidos, lo cual es detectado a partir del contenido de la página).

## Firma

```python
news.article(
    article_id: int,
) -> NewsArticle
```

## Ejemplos

### Obtener un artículo

```python
import vlrdevapi

article = vlrdevapi.news.article(734100)
print(f"{article.title}")
print(f"Por {article.author} el {article.date}")
print(f"Evento: {article.event_name}")
print(article.content)
```

### Leer el artículo en formato Markdown

```python
import vlrdevapi

article = vlrdevapi.news.article(734100)
print(article.content_md)
```

### Leer un artículo encontrado en la lista de noticias

```python
import vlrdevapi

page = vlrdevapi.news(page=1)
article_id = page.news[0].id
article = vlrdevapi.news.article(article_id)
print(article.title)
```
