`news()` returns a paginated list of news items from vlr.gg.

## Signature

```python

    page: int = 1,
) -> NewsPage
```

## Examples

### Fetch the latest news

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
print(f"News items on this page: {len(result.news)}")
print(f"More pages available: {result.has_next_page}")

for item in result.news:
    print(f"{item.date.date()} | {item.title} | by {item.author}")
```

### Filter by country

```python
import vlrdevapi

result = vlrdevapi.news(page=1)
local_news = [n for n in result.news if n.country_name == "Brazil"]
for n in local_news:
    print(f"{n.title} - {n.author}")
```
