title: Próximas Partidas del Equipo (Team Upcoming Matches)
description: "Obtén los próximos partidos programados de un equipo con información del rival, torneo y fecha y hora de inicio."

`team.upcoming_matches(team_id)` devuelve las próximas partidas programadas de un equipo en vlr.gg.

## Firma

```python
team.upcoming_matches(team_id: int) -> TeamUpcomingMatches
```

}} />

## Ejemplos

### Listar próximas partidas

```python
import vlrdevapi

upcoming = vlrdevapi.team.upcoming_matches(team_id=2593)
if not upcoming.matches:
    print("No hay partidas programadas para este equipo")
for m in upcoming.matches:
    opp = m.opponent.name if m.opponent else "Por determinar"
    round_label = " ".join(part for part in (m.stage, m.bracket) if part)
    print(f"vs {opp} ({m.event} - {round_label}) el {m.datetime}")
```

### Acceso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
upcoming = team.upcoming_matches()
if not upcoming.matches:
    print("No hay próximas partidas")
for m in upcoming.matches:
    opp = m.opponent.tag if m.opponent else "?"
    print(f"Próxima cita: vs {opp} en {m.event}")
```
