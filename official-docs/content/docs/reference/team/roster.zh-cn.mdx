`team.roster(team_id)` 返回指定战队在 vlr.gg 上的当前成员名单，涵盖选手与教练管理人员。

## 函数签名

```python
team.roster(team_id: int) -> TeamRoster
```

## 示例

### 查看现役选手

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
print(f"选手列表 ({len(roster.players)} 人):")
for p in roster.players:
    cap = " (队长)" if p.is_captain else ""
    status = ""
    if not p.is_active:
        status = " [非活跃]"
    elif p.is_sub:
        status = " [替补]"
    print(f"  {p.ign}{cap} - {p.real_name} ({p.country}){status}")
```

### 查看教练与战队职员

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
print(f"教练团队 ({len(roster.staff)} 人):")
for s in roster.staff:
    print(f"  {s.ign} - {', '.join(s.roles)}")
```

### 筛选替补与非活跃选手

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
subs = [p.ign for p in roster.players if p.is_sub]
inactive = [p.ign for p in roster.players if not p.is_active]
print(f"替补名单: {subs}")
print(f"非活跃队员: {inactive}")
```

### 柯里化链式访问

```python
import vlrdevapi

team = vlrdevapi.team(2593)
roster = team.roster()
for p in roster.players:
    print(f"{p.ign} ({p.real_name})")
