---
title: Partidas Finalizadas del Equipo (Team Completed Matches)
description: "Obtén el historial de partidas finalizadas de un equipo con tanteos, rivales, resultado victoria/derrota y detalles del torneo."
---

`team.completed_matches(team_id)` devuelve el historial de partidas completadas por un equipo en vlr.gg.

Por defecto devuelve las primeras **50** partidas (primera página de vlr.gg). Ajusta `limit` para traer más, o pasa `return_all=True` para descargar todas las páginas disponibles.

## Firma

```python
team.completed_matches(
    team_id: int,
    limit: int = 50,
    return_all: bool = False,
) -> TeamCompletedMatches
```

## Ejemplos

### Resultados recientes

```python
import vlrdevapi

history = vlrdevapi.team.completed_matches(team_id=2593)
print(f"Partidas finalizadas del equipo {history.team_id}:")
for m in history.matches[:10]:
    result = "VICTORIA" if m.is_win else "derrota"
    opp = m.opponent.name if m.opponent else "Por determinar"
    round_label = " ".join(part for part in (m.stage, m.bracket) if part)
    print(
        f"  {m.team_score} - {m.opponent_score} vs {opp} "
        f"({result}) - {m.event} {round_label}"
    )
```

### Registro de victorias y derrotas

```python
import vlrdevapi

history = vlrdevapi.team.completed_matches(team_id=2593)
wins = sum(1 for m in history.matches if m.is_win)
losses = sum(1 for m in history.matches if not m.is_win)
total = wins + losses
pct = wins / total * 100 if total else 0
print(f"{wins}V - {losses}D ({pct:.0f}% efectividad) en {total} encuentros")
```

### Acceso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
history = team.completed_matches()
for m in history.matches[:5]:
    tag = m.opponent.tag if m.opponent else "TBD"
    print(f"{'V' if m.is_win else 'D'} {m.team_score}-{m.opponent_score} vs {tag}")
```
