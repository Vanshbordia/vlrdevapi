---
title: Partidas Finalizadas da Equipe (Team Completed Matches)
description: "Obtenha o histórico de partidas concluídas de uma equipe com placares, adversários, vitória/derrota e contexto de torneio."
---

`team.completed_matches(team_id)` retorna o histórico de partidas finalizadas de uma equipe no vlr.gg.

Por padrão, retorna as primeiras **50** partidas (primeira página do vlr.gg). Defina `limit` para buscar mais, ou utilize `return_all=True` para buscar todas as páginas.

## Assinatura

```python
team.completed_matches(
    team_id: int,
    limit: int = 50,
    return_all: bool = False,
) -> TeamCompletedMatches
```

## Exemplos

### Resultados recentes

```python
import vlrdevapi

history = vlrdevapi.team.completed_matches(team_id=2593)
print(f"Partidas finalizadas da equipe {history.team_id}:")
for m in history.matches[:10]:
    result = "VENCEU" if m.is_win else "derrota"
    opp = m.opponent.name if m.opponent else "A definir"
    round_label = " ".join(part for part in (m.stage, m.bracket) if part)
    print(
        f"  {m.team_score} - {m.opponent_score} vs {opp} "
        f"({result}) - {m.event} {round_label}"
    )
```

### Análise de vitórias e derrotas

```python
import vlrdevapi

history = vlrdevapi.team.completed_matches(team_id=2593)
wins = sum(1 for m in history.matches if m.is_win)
losses = sum(1 for m in history.matches if not m.is_win)
total = wins + losses
pct = wins / total * 100 if total else 0
print(f"{wins}V - {losses}D ({pct:.0f}% taxa de vitória) em {total} partidas")
```

### Acesso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
history = team.completed_matches()
for m in history.matches[:5]:
    tag = m.opponent.tag if m.opponent else "TBD"
    print(f"{'V' if m.is_win else 'D'} {m.team_score}-{m.opponent_score} vs {tag}")
```
