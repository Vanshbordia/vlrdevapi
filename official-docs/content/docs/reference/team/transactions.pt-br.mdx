`team.transactions(team_id)` retorna o histórico de movimentações e transferências de integrantes do elenco de uma equipe no vlr.gg.

## Assinatura

```python
team.transactions(team_id: int) -> TeamTransactions
```

## Exemplos

### Transferências recentes

```python
import vlrdevapi

history = vlrdevapi.team.transactions(team_id=2593)
print(f"Histórico de transferências da equipe {history.team_id}:")
for t in history.transactions[:10]:
    print(f"  {t.date}: {t.player.ign} {t.action.value} ({t.position})")
```

### Contabilizar contratações vs saídas

```python
from collections import Counter
import vlrdevapi

history = vlrdevapi.team.transactions(team_id=2593)
counts = Counter(t.action.value for t in history.transactions)
print(f"Entradas: {counts.get('Join', 0)}")
print(f"Saídas: {counts.get('Leave', 0)}")
print(f"Inativos: {counts.get('Inactive', 0)}")
```

### Acesso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
history = team.transactions()
for t in history.transactions[:5]:
    print(f"{t.date}: {t.player.ign} -> {t.action.value}")
