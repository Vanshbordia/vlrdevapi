`team.info(team_id)` devuelve información detallada de un equipo en vlr.gg.

## Firma

```python
team.info(team_id: int) -> TeamInfo
```

## Ejemplos

### Búsqueda básica de un equipo

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=2593)
print(f"{info.name} ({info.tag})")
print(f"País: {info.country}")
print(f"Activo: {info.is_active}")
print(f"Logo claro: {info.light_logo_url}")
print(f"Logo oscuro: {info.dark_logo_url}")
```

### Redes sociales oficiales

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=2593)
if info.socials:
    for s in info.socials:
        print(f"{s.name}: {s.url}")
```

### Linaje y cambios de marca (rebranding)

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=682)
prev = ', '.join(t.name for t in info.previous_teams) if info.previous_teams else "(ninguno)"
curr = ', '.join(t.name for t in info.current_teams) if info.current_teams else "(ninguno)"
print(f"Conocido anteriormente como: {prev}")
print(f"Conocido actualmente como: {curr}")
```

### Acceso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
info = team.info()
print(f"{info.name} ({info.tag}) - {info.country}")
```
