---
title: Estadísticas del Equipo (Team Stats)
description: "Obtén estadísticas de mapas y composiciones de agentes de un equipo en un rango de fechas con filtros opcionales de eventos o series."
---

`team.stats(team_id, ...)` devuelve estadísticas por mapa para un equipo en vlr.gg con flexibilidad en el filtrado por fechas y datos opcionales sobre composiciones de agentes.

## Firma

```python
team.stats(
    team_id: int,
    date_start: date | None = None,
    date_end: date | None = None,
    event_id: int | None = None,
    series_id: int | None = None,
    subseries_id: int | None = None,
    last_days: int | None = None,
    agent_composition: AgentCompositionLevel = "none",
) -> TeamStats
```

## Ejemplos

### Estadísticas por defecto (últimos 30 días)

```python
# doc-check: allow-empty
import vlrdevapi

stats = vlrdevapi.team.stats(team_id=2593)
print(f"Estadísticas de mapa para el equipo {stats.team_id}:")
for m in stats.maps:
    wr = f"{m.win_rate:.0f}%" if m.win_rate is not None else "N/A"
    atk_wr = f"{m.attack_round_win_rate:.0f}%" if m.attack_round_win_rate is not None else "N/A"
    def_wr = f"{m.defense_round_win_rate:.0f}%" if m.defense_round_win_rate is not None else "N/A"
    print(f"  {m.map_name}: {m.games_played}p | {wr} WR | ATK {atk_wr} | DEF {def_wr}")
```

### Análisis de composiciones de agentes

```python
# doc-check: allow-empty
import vlrdevapi

stats = vlrdevapi.team.stats(team_id=2593, last_days=90, agent_composition="basic")
for m in stats.maps:
    print(f"\n{m.map_name}:")
    if m.compositions:
        for comp in m.compositions[:3]:
            agents = ", ".join(comp.agents)
            print(f"  [{agents}] {comp.games_played}p - {comp.wins}V / {comp.losses}D ({comp.win_rate:.0f}%)")
    else:
        print("  (sin datos de composiciones)")
```

### Acceso curried

```python
# doc-check: allow-empty
import vlrdevapi

team = vlrdevapi.team(2593)
stats = team.stats(last_days=90)
if stats.maps:
    best_map = max(stats.maps, key=lambda m: m.win_rate or 0)
    print(f"Mejor mapa: {best_map.map_name} ({best_map.win_rate:.0f}% WR)")
else:
    print("(sin estadísticas de mapas disponibles)")
```
