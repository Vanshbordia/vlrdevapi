---
title: Clasificaciones del Equipo (Team Placements)
description: "Obtén el historial de posiciones en torneos de un equipo: puestos alcanzados, premios económicos y recaudación acumulada."
---

`team.placements(team_id)` devuelve el historial de clasificaciones en torneos y premios monetarios conseguidos por un equipo en vlr.gg.

## Firma

```python
team.placements(team_id: int) -> TeamPlacements
```

## Parámetros

<TypeTable type={{

    typeDescription: "Entero positivo",
    required: true,

}} />

## Ejemplos

### Todas las clasificaciones

```python
import vlrdevapi

placements = vlrdevapi.team.placements(team_id=2593)
total = f"{placements.total_winnings_currency}{placements.total_winnings:,}" if placements.total_winnings and placements.total_winnings_currency else "N/A"
print(f"Ganancias totales: {total}")
print()
for event in placements.placements:
    for p in event.placements:
        print(f"{event.year} {event.event_name}: {p.placement} en {p.stage}")
```

### Ganancias desglosadas por año

```python
import vlrdevapi

placements = vlrdevapi.team.placements(team_id=2593)
by_year = {}
for event in placements.placements:
    by_year[event.year] = by_year.get(event.year, 0) + (event.prize or 0)
currency = placements.total_winnings_currency or "$"
for year in sorted(by_year):
    print(f"  {year}: {currency}{by_year[year]:,}")
```

### Acceso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
placements = team.placements()
wins = [e for e in placements.placements for p in (e.placements or []) if "1st" in p.placement]
print(f"Torneos ganados: {len(wins)}")
for e in wins:
    print(f"  {e.event_name} ({e.year})")
