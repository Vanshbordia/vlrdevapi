`team.transactions(team_id)` devuelve el historial de traspasos y modificaciones de plantilla de un equipo en vlr.gg.

## Firma

```python
team.transactions(team_id: int) -> TeamTransactions
```

## Ejemplos

### Fichajes recientes

```python
import vlrdevapi

history = vlrdevapi.team.transactions(team_id=2593)
print(f"Historial de movimientos del equipo {history.team_id}:")
for t in history.transactions[:10]:
    print(f"  {t.date}: {t.player.ign} {t.action.value} ({t.position})")
```

### Contar altas y bajas

```python
from collections import Counter
import vlrdevapi

history = vlrdevapi.team.transactions(team_id=2593)
counts = Counter(t.action.value for t in history.transactions)
print(f"Fichajes (altas): {counts.get('Join', 0)}")
print(f"Salidas (bajas): {counts.get('Leave', 0)}")
print(f"Inactivos: {counts.get('Inactive', 0)}")
```

### Acceso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
history = team.transactions()
for t in history.transactions[:5]:
    print(f"{t.date}: {t.player.ign} -> {t.action.value}")
