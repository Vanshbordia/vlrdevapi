---
title: 战队数据统计 (Team Stats)
description: "获取战队在可配置日期范围内的地图与特工阵容统计，支持按赛事/系列赛过滤以及细化特工阵容数据。"
---

`team.stats(team_id, ...)` 返回指定战队在 vlr.gg 上的地图级竞技统计数据，支持灵活的日期区间筛选以及可选的特工阵容胜率分析。

## 函数签名

```python
team.stats(
    team_id: int,
    date_start: date | None = None,
    date_end: date | None = None,
    event_id: int | None = None,
    series_id: int | None = None,
    subseries_id: int | None = None,
    last_days: int | None = None,
    agent_composition: AgentCompositionLevel = "none",
) -> TeamStats
```

## 示例

### 默认查询最近 30 天的地图数据

```python
# doc-check: allow-empty
import vlrdevapi

stats = vlrdevapi.team.stats(team_id=2593)
print(f"战队 {stats.team_id} 的地图战绩:")
for m in stats.maps:
    wr = f"{m.win_rate:.0f}%" if m.win_rate is not None else "N/A"
    atk_wr = f"{m.attack_round_win_rate:.0f}%" if m.attack_round_win_rate is not None else "N/A"
    def_wr = f"{m.defense_round_win_rate:.0f}%" if m.defense_round_win_rate is not None else "N/A"
    print(f"  {m.map_name}: {m.games_played} 场 | {wr} 胜率 | 攻 {atk_wr} | 防 {def_wr}")
```

### 分析特工阵容出场与胜率

```python
# doc-check: allow-empty
import vlrdevapi

stats = vlrdevapi.team.stats(team_id=2593, last_days=90, agent_composition="basic")
for m in stats.maps:
    print(f"\n{m.map_name}:")
    if m.compositions:
        for comp in m.compositions[:3]:
            agents = ", ".join(comp.agents)
            print(f"  [{agents}] {comp.games_played}局 - {comp.wins}胜 / {comp.losses}负 ({comp.win_rate:.0f}%)")
    else:
        print("  (暂无特工阵容数据)")
```

### 柯里化链式访问

```python
# doc-check: allow-empty
import vlrdevapi

team = vlrdevapi.team(2593)
stats = team.stats(last_days=90)
if stats.maps:
    best_map = max(stats.maps, key=lambda m: m.win_rate or 0)
    print(f"胜率最高的主场地图: {best_map.map_name} (胜率 {best_map.win_rate:.0f}%)")
else:
    print("(暂无地图表现数据)")
```
