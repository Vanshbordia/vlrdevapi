`team.roster(team_id)` retorna o elenco atual de uma equipe no vlr.gg, incluindo jogadores e equipe técnica.

## Assinatura

```python
team.roster(team_id: int) -> TeamRoster
```

## Exemplos

### Listar jogadores ativos

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
print(f"Jogadores ({len(roster.players)}):")
for p in roster.players:
    cap = " (c)" if p.is_captain else ""
    status = ""
    if not p.is_active:
        status = " [inativo]"
    elif p.is_sub:
        status = " [reserva]"
    print(f"  {p.ign}{cap} - {p.real_name} ({p.country}){status}")
```

### Listar comissão técnica

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
print(f"Comissão Técnica ({len(roster.staff)}):")
for s in roster.staff:
    print(f"  {s.ign} - {', '.join(s.roles)}")
```

### Identificar reservas e inativos

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
subs = [p.ign for p in roster.players if p.is_sub]
inactive = [p.ign for p in roster.players if not p.is_active]
print(f"Reservas: {subs}")
print(f"Inativos: {inactive}")
```

### Acesso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
roster = team.roster()
for p in roster.players:
    print(f"{p.ign} ({p.real_name})")
```
