`team.transactions(team_id)` 返回指定战队在 vlr.gg 上的历史阵容转会与人员流动记录。

## 函数签名

```python
team.transactions(team_id: int) -> TeamTransactions
```

## 示例

### 查看近期人员变动

```python
import vlrdevapi

history = vlrdevapi.team.transactions(team_id=2593)
print(f"战队 {history.team_id} 的人员变动历史:")
for t in history.transactions[:10]:
    print(f"  {t.date}: {t.player.ign} {t.action.value} ({t.position})")
```

### 统计加盟与离队次数

```python
from collections import Counter
import vlrdevapi

history = vlrdevapi.team.transactions(team_id=2593)
counts = Counter(t.action.value for t in history.transactions)
print(f"加入 (Join): {counts.get('Join', 0)}")
print(f"离队 (Leave): {counts.get('Leave', 0)}")
print(f"转替补/非活跃 (Inactive): {counts.get('Inactive', 0)}")
```

### 柯里化链式访问

```python
import vlrdevapi

team = vlrdevapi.team(2593)
history = team.transactions()
for t in history.transactions[:5]:
    print(f"{t.date}: {t.player.ign} -> {t.action.value}")
