`team.upcoming_matches(team_id)` retorna as próximas partidas agendadas de uma equipe no vlr.gg.

## Assinatura

```python
team.upcoming_matches(team_id: int) -> TeamUpcomingMatches
```

## Exemplos

### Listar próximas partidas

```python
import vlrdevapi

upcoming = vlrdevapi.team.upcoming_matches(team_id=2593)
if not upcoming.matches:
    print("Nenhuma partida agendada para esta equipe")
for m in upcoming.matches:
    opp = m.opponent.name if m.opponent else "A definir"
    round_label = " ".join(part for part in (m.stage, m.bracket) if part)
    print(f"vs {opp} ({m.event} - {round_label}) em {m.datetime}")
```

### Acesso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
upcoming = team.upcoming_matches()
if upcoming.matches:
    m = upcoming.matches[0]
    opp = m.opponent.tag if m.opponent else "?"
    print(f"Próxima partida: vs {opp} em {m.event}")
