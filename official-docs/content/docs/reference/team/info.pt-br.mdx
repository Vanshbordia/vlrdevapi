`team.info(team_id)` retorna informações detalhadas de uma equipe no vlr.gg.

## Assinatura

```python
team.info(team_id: int) -> TeamInfo
```

## Exemplos

### Consulta básica da equipe

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=2593)
print(f"{info.name} ({info.tag})")
print(f"País: {info.country}")
print(f"Em atividade: {info.is_active}")
print(f"Logo tema claro: {info.light_logo_url}")
print(f"Logo tema escuro: {info.dark_logo_url}")
```

### Links de redes sociais

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=2593)
if info.socials:
    for s in info.socials:
        print(f"{s.name}: {s.url}")
```

### Linhagem e rebrands

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=682)
prev = ', '.join(t.name for t in info.previous_teams) if info.previous_teams else "(nenhuma)"
curr = ', '.join(t.name for t in info.current_teams) if info.current_teams else "(nenhuma)"
print(f"Anteriormente conhecida como: {prev}")
print(f"Atualmente conhecida como: {curr}")
```

### Acesso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
info = team.info()
print(f"{info.name} ({info.tag}) - {info.country}")
```
