`team.upcoming_matches(team_id)` 返回指定战队在 vlr.gg 上即将进行的所有预定赛程安排。

## 函数签名

```python
team.upcoming_matches(team_id: int) -> TeamUpcomingMatches
```

## 示例

### 查看未来赛程

```python
import vlrdevapi

upcoming = vlrdevapi.team.upcoming_matches(team_id=2593)
if not upcoming.matches:
    print("该战队暂无未来预定赛程")
for m in upcoming.matches:
    opp = m.opponent.name if m.opponent else "待定"
    round_label = " ".join(part for part in (m.stage, m.bracket) if part)
    print(f"对阵 {opp} ({m.event} - {round_label})，开赛时间: {m.datetime}")
```

### 柯里化链式访问

```python
import vlrdevapi

team = vlrdevapi.team(2593)
upcoming = team.upcoming_matches()
if not upcoming.matches:
    print("暂无即将进行的比赛")
for m in upcoming.matches:
    opp = m.opponent.tag if m.opponent else "?"
    print(f"下一场比赛: 对阵 {opp} ({m.event})")
```
