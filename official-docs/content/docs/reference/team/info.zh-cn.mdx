`team.info(team_id)` 返回指定战队在 vlr.gg 上的详细基础资料。

## 函数签名

```python

## 示例

### 基础查询战队信息

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=2593)
print(f"{info.name} ({info.tag})")
print(f"国家/地区: {info.country}")
print(f"活跃状态: {info.is_active}")
print(f"浅色 Logo: {info.light_logo_url}")
print(f"深色 Logo: {info.dark_logo_url}")
```

### 查看官方社交媒体链接

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=2593)
if info.socials:
    for s in info.socials:
        print(f"{s.name}: {s.url}")
```

### 追踪战队更名前身与后继

```python
import vlrdevapi

info = vlrdevapi.team.info(team_id=682)
prev = ', '.join(t.name for t in info.previous_teams) if info.previous_teams else "(无)"
curr = ', '.join(t.name for t in info.current_teams) if info.current_teams else "(无)"
print(f"历史前身战队: {prev}")
print(f"重组后继战队: {curr}")
```

### 柯里化链式访问

```python
import vlrdevapi

team = vlrdevapi.team(2593)
info = team.info()
print(f"{info.name} ({info.tag}) - {info.country}")
