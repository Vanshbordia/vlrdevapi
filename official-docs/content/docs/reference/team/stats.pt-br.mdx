---
title: Estatísticas da Equipe (Team Stats)
description: "Obtenha estatísticas de mapas e agentes de uma equipe em um intervalo de datas configurável, com filtros opcionais por evento/série e composições detalhadas."
---

`team.stats(team_id, ...)` retorna estatísticas ao nível de mapa para uma equipe no vlr.gg, com filtragem flexível por data e dados opcionais sobre composições de agentes.

## Assinatura

```python
team.stats(
    team_id: int,
    date_start: date | None = None,
    date_end: date | None = None,
    event_id: int | None = None,
    series_id: int | None = None,
    subseries_id: int | None = None,
    last_days: int | None = None,
    agent_composition: AgentCompositionLevel = "none",
) -> TeamStats
```

## Exemplos

### Estatísticas padrão (últimos 30 dias)

```python
# doc-check: allow-empty
import vlrdevapi

stats = vlrdevapi.team.stats(team_id=2593)
print(f"Estatísticas de mapas da equipe {stats.team_id}:")
for m in stats.maps:
    wr = f"{m.win_rate:.0f}%" if m.win_rate is not None else "N/A"
    atk_wr = f"{m.attack_round_win_rate:.0f}%" if m.attack_round_win_rate is not None else "N/A"
    def_wr = f"{m.defense_round_win_rate:.0f}%" if m.defense_round_win_rate is not None else "N/A"
    print(f"  {m.map_name}: {m.games_played}j | {wr} WR | ATK {atk_wr} | DEF {def_wr}")
```

### Análise de composições de agentes

```python
# doc-check: allow-empty
import vlrdevapi

stats = vlrdevapi.team.stats(team_id=2593, last_days=90, agent_composition="basic")
for m in stats.maps:
    print(f"\n{m.map_name}:")
    if m.compositions:
        for comp in m.compositions[:3]:
            agents = ", ".join(comp.agents)
            print(f"  [{agents}] {comp.games_played}j - {comp.wins}V / {comp.losses}D ({comp.win_rate:.0f}%)")
    else:
        print("  (sem dados de composição)")
```

### Acesso curried

```python
# doc-check: allow-empty
import vlrdevapi

team = vlrdevapi.team(2593)
stats = team.stats(last_days=90)
if stats.maps:
    best_map = max(stats.maps, key=lambda m: m.win_rate or 0)
    print(f"Melhor mapa: {best_map.map_name} ({best_map.win_rate:.0f}% WR)")
else:
    print("(sem estatísticas de mapas disponíveis)")
```
