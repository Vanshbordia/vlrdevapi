`team.roster(team_id)` devuelve la plantilla activa de un equipo en vlr.gg, desglosando jugadores y equipo técnico.

## Firma

```python
team.roster(team_id: int) -> TeamRoster
```

## Ejemplos

### Listar jugadores activos

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
print(f"Jugadores ({len(roster.players)}):")
for p in roster.players:
    cap = " (c)" if p.is_captain else ""
    status = ""
    if not p.is_active:
        status = " [inactivo]"
    elif p.is_sub:
        status = " [suplente]"
    print(f"  {p.ign}{cap} - {p.real_name} ({p.country}){status}")
```

### Listar cuerpo técnico

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
print(f"Cuerpo Técnico ({len(roster.staff)}):")
for s in roster.staff:
    print(f"  {s.ign} - {', '.join(s.roles)}")
```

### Consultar suplentes e inactivos

```python
import vlrdevapi

roster = vlrdevapi.team.roster(team_id=2593)
subs = [p.ign for p in roster.players if p.is_sub]
inactive = [p.ign for p in roster.players if not p.is_active]
print(f"Suplentes: {subs}")
print(f"Inactivos: {inactive}")
```

### Acceso curried

```python
import vlrdevapi

team = vlrdevapi.team(2593)
roster = team.roster()
for p in roster.players:
    print(f"{p.ign} ({p.real_name})")
```
