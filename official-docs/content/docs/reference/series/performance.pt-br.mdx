---
title: Desempenho da Série (Series Performance)
description: "Obtenha dados de desempenho avançados - matrizes de eliminações (todos os abates, first kills, kills de Operator) e estatísticas de multikills e clutches."
---

`series.performance(series_id, game_id)` retorna dados detalhados de desempenho para um mapa da série ou consolidados para toda a partida, incluindo matrizes completas de duelos diretos e estatísticas avançadas.

## Assinatura

```python
series.performance(
    series_id: int,
    game_id: int | str = "all",
) -> PerformanceData
```

Com acesso curried:

```python
vlrdevapi.series(series_id).performance(game_id: int | str = "all") -> PerformanceData
```

## Exemplos

### Consultar a matriz de abates

```python
import vlrdevapi

perf = vlrdevapi.series.performance(series_id=670471, game_id=1)

if perf.all_kills_matrix.entries:
    for entry in perf.all_kills_matrix.entries[:5]:
        print(f"{entry.killer} ({entry.killer_team}) eliminou {entry.victim} ({entry.victim_team})")
```

### Estatísticas avançadas e clutches

```python
import vlrdevapi

perf = vlrdevapi.series.performance(series_id=670471, game_id=1)
for p in perf.adv_stats[:5]:
    print(f"{p.name} [{p.agent}]: 2K={p.two_k} | 3K={p.three_k} | 4K={p.four_k} | Ace={p.five_k} | Clutches 1v2={p.one_v2}")
```

### Acesso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
perf = series.performance(game_id=1)
if perf.adv_stats:
    top_clutcher = max(perf.adv_stats, key=lambda p: (p.one_v1 or 0) + (p.one_v2 or 0))
    print(f"Maior especialista em clutches: {top_clutcher.name}")
