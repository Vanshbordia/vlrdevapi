---
title: Economia da Série (Series Economy)
description: "Obtenha dados de economia por round para um mapa da partida - saldo bancário das equipes, gastos, tipo de compra, vencedor e matriz de compras."
---

`series.economy(series_id, game_id)` retorna dados econômicos detalhados para cada rodada de um mapa específico dentro de uma série no vlr.gg.

## Assinatura

```python
series.economy(
    series_id: int,
    game_id: int,
) -> EconomyData
```

Com acesso curried:

```python
vlrdevapi.series(series_id).economy(game_id: int) -> EconomyData
```

## Exemplos

### Percorrer a economia das rodadas

```python
import vlrdevapi

econ = vlrdevapi.series.economy(series_id=670471, game_id=1)
print(f"Economia: {econ.team1} vs {econ.team2}")
for r in econ.rounds[:5]:
    print(f"Round {r.round_number}: {econ.team1} ({r.buy_type_team1.value}, ${r.spent_team1}) vs {econ.team2} ({r.buy_type_team2.value}, ${r.spent_team2}) -> Vencedor: {r.winner.name}")
```

### Acesso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
econ = series.economy(game_id=1)
if econ.pistol_team1:
    print(f"{econ.team1} rounds de pistola: {econ.pistol_team1.won}/{econ.pistol_team1.total}")
