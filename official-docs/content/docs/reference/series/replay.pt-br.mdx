`series.replay(series_id, game_id)` retorna a linha do tempo de replay do kill-feed para cada rodada de um mapa específico dentro de uma série no vlr.gg (aba logs).

## Assinatura

```python
series.replay(
    series_id: int,
    game_id: int,
) -> ReplayData
```

Com acesso curried:

```python
vlrdevapi.series(series_id).replay(game_id: int) -> ReplayData
```

## Exemplos

### Kill-feed da Rodada 1

```python
import vlrdevapi

replay = vlrdevapi.series.replay(series_id=754737, game_id=283288)
print(f"{replay.team1} vs {replay.team2} ({replay.num_rounds} rounds)")

for ev in replay.round(1).events:
    who = ev.actor.name if ev.actor else "-"
    print(f"{ev.seq}. {ev.seconds}s {ev.type.full_name}: {who}", end="")
    if ev.cause:
        print(f" ({ev.cause})", end="")
    if ev.victim:
        print(f" -> {ev.victim.name}", end="")
    print()
```

### Plantas e detonação da Spike

```python
import vlrdevapi
from vlrdevapi._series.replay.models import ReplayEventType

replay = vlrdevapi.series.replay(series_id=754737, game_id=283288)

for ev in replay.round(14).events:
    if ev.type in (ReplayEventType.PLANT, ReplayEventType.DEFUSE, ReplayEventType.BOOM):
        print(f"{ev.clock or '-'} {ev.type.full_name} no bombsite {ev.site} em ({ev.pos_x}, {ev.pos_y})")
```

### Acesso curried

```python
import vlrdevapi

series = vlrdevapi.series(754737)
replay = series.replay(game_id=283288)
round_1 = replay.round(1)
for ld in round_1.loadouts[:4]:
    print(f"{ld.name} ({ld.agent}): {ld.weapon} + {ld.armor} (${ld.spent} gastos)")
