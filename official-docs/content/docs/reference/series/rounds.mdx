---
title: Series Rounds
description: Fetch round-by-round data for a specific game within a series - winner, win type, side, score progression, and per-round economy (bank, spend, buy tiers).
---

`series.rounds(series_id, game_id)` returns round-by-round data for a specific game within a series, including the per-round economy (bank, spend, buy tier) merged from the economy tab.

## Signature

```python
series.rounds(
    series_id: int,
    game_id: int,
) -> RoundsData
```

With curried access:

```python
vlrdevapi.series(series_id).rounds(game_id: int) -> RoundsData
```

## Examples

### Basic round data

Fetch every round in a game, showing the winner, win type, the side they were playing, and how much money each team had. This is useful for building score progression charts or understanding how the game swung.

```python
import vlrdevapi

rounds = vlrdevapi.series.rounds(series_id=670471, game_id=1)
print(f"{rounds.team1} vs {rounds.team2}")
print(f"Total rounds: {len(rounds.rounds)}")

for rd in rounds.rounds[:5]:
    print(f"R{rd.round_number}: {rd.winner_team_name} won ({rd.win_type.full_name}) on {rd.side}")
    print(f"  Score: {rd.team1_score} - {rd.team2_score}")
    print(f"  Buy: {rd.buy_type_team1} vs {rd.buy_type_team2} - bank {rd.bank_team1}/{rd.bank_team2}")
```

### Round economy timeline

The economy tab's per-round money data (bank, spend, buy tier) is merged into the same round records, so the round timeline is the single source for round-by-round analysis.

```python
import vlrdevapi

rounds = vlrdevapi.series.rounds(series_id=670471, game_id=1)
print("Round | Buy 1 vs Buy 2        | Spent 1 vs Spent 2 | Winner")
for rd in rounds.rounds:
    print(f"R{rd.round_number:>2}   | {rd.buy_type_team1} vs {rd.buy_type_team2:<8} | {rd.spent_team1} vs {rd.spent_team2} | {rd.winner_team_name}")
```

### Win type breakdown

Analyse how each team won their rounds - by elimination, spike detonation, defuse, or time expiry.

```python
import vlrdevapi
from collections import Counter

rounds = vlrdevapi.series.rounds(series_id=670471, game_id=1)

team1_wins = [r for r in rounds.rounds if r.winner_team_name == rounds.team1]
team2_wins = [r for r in rounds.rounds if r.winner_team_name == rounds.team2]

print(f"{rounds.team1}: {Counter(r.win_type.full_name for r in team1_wins)}")
print(f"{rounds.team2}: {Counter(r.win_type.full_name for r in team2_wins)}")
```

### Score progression

Generate a round-by-round score progression for both teams, useful for visualising match momentum.

```python
import vlrdevapi

rounds = vlrdevapi.series.rounds(series_id=670471, game_id=1)
print("Round | Score")
for rd in rounds.rounds:
    print(f"R{rd.round_number:>2}  | {rd.team1_score} - {rd.team2_score}")
```

### Curried access

Use the curried pattern to inspect specific pistol rounds.

```python
import vlrdevapi

series = vlrdevapi.series(670471)
rounds = series.rounds(game_id=1)
pistol_rounds = [r for r in rounds.rounds if r.is_pistol_round]
for rd in pistol_rounds:
    print(f"Pistol R{rd.round_number}: won by {rd.winner_team_name}")
```
