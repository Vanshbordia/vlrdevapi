---
title: Replay de la Serie (Series Replay)
description: "Obtén la cronología del kill-feed ronda por ronda: bajas con armas y coordenadas espaciales, plantas/desactivaciones de Spike, resurrecciones y ángulos de visión."
---

`series.replay(series_id, game_id)` devuelve la línea temporal del registro de bajas (kill-feed) para cada ronda de un mapa específico dentro de una serie en vlr.gg (pestaña logs).

## Firma

```python
series.replay(
    series_id: int,
    game_id: int,
) -> ReplayData
```

Con acceso curried:

```python
vlrdevapi.series(series_id).replay(game_id: int) -> ReplayData
```

## Ejemplos

### Registro del kill-feed en la Ronda 1

```python
import vlrdevapi

replay = vlrdevapi.series.replay(series_id=754737, game_id=283288)
print(f"{replay.team1} vs {replay.team2} ({replay.num_rounds} rondas)")

for ev in replay.round(1).events:
    who = ev.actor.name if ev.actor else "-"
    print(f"{ev.seq}. {ev.seconds}s {ev.type.full_name}: {who}", end="")
    if ev.cause:
        print(f" ({ev.cause})", end="")
    if ev.victim:
        print(f" -> {ev.victim.name}", end="")
    print()
```

### Plantas y explosiones de Spike

```python
import vlrdevapi
from vlrdevapi._series.replay.models import ReplayEventType

replay = vlrdevapi.series.replay(series_id=754737, game_id=283288)

for ev in replay.round(14).events:
    if ev.type in (ReplayEventType.PLANT, ReplayEventType.DEFUSE, ReplayEventType.BOOM):
        print(f"{ev.clock or '-'} {ev.type.full_name} zona {ev.site} en ({ev.pos_x}, {ev.pos_y})")
```

### Acceso curried

```python
import vlrdevapi

series = vlrdevapi.series(754737)
replay = series.replay(game_id=283288)
round_1 = replay.round(1)
for ld in round_1.loadouts[:4]:
    print(f"{ld.name} ({ld.agent}): {ld.weapon} + {ld.armor} (${ld.spent} gastados)")
```
