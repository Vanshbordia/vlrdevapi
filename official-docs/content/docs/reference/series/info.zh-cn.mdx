---
title: 比赛系列赛总览 (Series Info)
description: "获取单场比赛的总览信息：参赛队伍、最终大比分、所属赛事、历史交锋、BP 选图及分地图比分。"
---

`series.info(series_id)` 返回 vlr.gg 网站上单场比赛（系列赛）的总览信息，包括两队资料、系列赛大比分、赛事背景、BP 地图禁选记录以及各小局的比分结果。

## 函数签名

```python
series.info(series_id: int) -> SeriesInfo
```

通过柯里化链式访问：

```python
vlrdevapi.series(series_id).info() -> SeriesInfo
```

## 示例

### 查看比赛对阵总览

```python
import vlrdevapi

info = vlrdevapi.series.info(series_id=670471)
print(f"{info.team1.name} {info.score1} - {info.score2} {info.team2.name}")
print(f"所属赛事: {info.event_name} ({info.stage})")
print(f"比赛状态: {info.status}")
for g in info.games:
    if g.played:
        print(f"  {g.map_name}: {g.team1_score} - {g.team2_score}")
```

### 柯里化链式访问

```python
import vlrdevapi

series = vlrdevapi.series(670471)
info = series.info()
print(f"选图 BP 记录 ({len(info.veto)} 条):")
for v in info.veto:
    print(f"  {v.team} {v.veto_type} {v.map_name}")
```
