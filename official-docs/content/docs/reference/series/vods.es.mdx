---
title: Retransmisiones y VODs de la Serie (Series Streams & VODs)
description: "Obtén los enlaces de directos, watch parties y vídeos bajo demanda (VODs) de un partido: Twitch, YouTube, Kick y plataformas regionales."
---

`series.vods(series_id)` devuelve los canales de emisión en directo y los enlaces a VODs (vídeos grabados) mostrados en la página del partido en vlr.gg. Las retransmisiones oficiales y watch parties se encuentran disponibles incluso para partidos programados; los vídeos completos y por mapa se listan una vez finalizado el encuentro.

## Firma

```python
series.vods(series_id: int) -> SeriesVods
```

Con acceso curried:

```python
vlrdevapi.series(series_id).vods() -> SeriesVods
```

## Ejemplos

### Listar retransmisiones en directo

```python
import vlrdevapi

vod_data = vlrdevapi.series.vods(series_id=670471)
print(f"Directos disponibles ({len(vod_data.streams)}):")
for s in vod_data.streams[:3]:
    print(f"  [{s.platform.upper()}] {s.channel} ({s.country_code}): {s.url}")
```

### Obtener enlaces a VODs

```python
import vlrdevapi

vod_data = vlrdevapi.series.vods(series_id=670471)
print(f"Vídeos encontrados ({len(vod_data.vods)}):")
for v in vod_data.vods[:3]:
    print(f"  {v.label}: {v.url}")
```

### Acceso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
vod_data = series.vods()
for v in vod_data.vods[:3]:
    print(f"{v.label} -> {v.url}")
```
