---
title: Rounds da Série (Series Rounds)
description: "Obtenha dados round a round de um mapa específico de uma série - vencedor, tipo de vitória, lado e economia detalhada da rodada."
---

`series.rounds(series_id, game_id)` retorna os dados de cada round para uma partida específica dentro da série, integrando inclusive as informações de economia por rodada (saldo bancário, gastos e tipo de compra) a partir da aba de economia do vlr.gg.

## Assinatura

```python
series.rounds(
    series_id: int,
    game_id: int,
) -> RoundsData
```

Com acesso curried:

```python
vlrdevapi.series(series_id).rounds(game_id: int) -> RoundsData
```

## Exemplos

### Percorrer a progressão dos rounds

```python
import vlrdevapi

rounds_data = vlrdevapi.series.rounds(series_id=670471, game_id=1)
print(f"Partida: {rounds_data.team1} vs {rounds_data.team2}")
for r in rounds_data.rounds:
    win_team = rounds_data.team1 if r.winner == "team1" else rounds_data.team2
    print(f"Round {r.round_number:2d}: {r.team1_score}-{r.team2_score} | Vencedor: {win_team} por {r.win_type}")
```

### Acesso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
rounds_data = series.rounds(game_id=1)
clutches_defuses = [r for r in rounds_data.rounds if r.win_type == "defuse"]
print(f"Rounds vencidos no defuse: {len(clutches_defuses)}")
