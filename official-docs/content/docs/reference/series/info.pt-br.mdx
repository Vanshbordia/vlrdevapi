---
title: Informações da Série (Series Info)
description: "Obtenha dados gerais da partida - equipes, placares, evento, confrontos diretos, vetos de mapas e estatísticas por jogo."
---

`series.info(series_id)` retorna as informações gerais de uma partida no vlr.gg, incluindo dados das equipes, placares de mapas, contexto do torneio, histórico de confrontos diretos, vetos e escolhas de mapas e estatísticas de cada mapa disputado.

## Assinatura

```python
series.info(series_id: int) -> SeriesInfo
```

Com acesso curried:

```python
vlrdevapi.series(series_id).info() -> SeriesInfo
```

## Exemplos

### Visão geral do confronto

```python
import vlrdevapi

info = vlrdevapi.series.info(series_id=670471)
print(f"{info.team1.name} {info.score1} - {info.score2} {info.team2.name}")
print(f"Torneio: {info.event_name} ({info.stage})")
print(f"Status: {info.status}")
for g in info.games:
    if g.played:
        print(f"  {g.map_name}: {g.team1_score} - {g.team2_score}")
```

### Acesso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
info = series.info()
print(f"Vetos da partida ({len(info.veto)}):")
for v in info.veto:
    print(f"  {v.team} {v.veto_type} {v.map_name}")
```
