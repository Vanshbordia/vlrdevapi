---
title: 比赛直播流与录像 (Series Streams & VODs)
description: "获取单场比赛的官方直播流、二路观赛频道以及全场/分地图的录像回放 (VOD) 链接。"
---

`series.vods(series_id)` 返回 vlr.gg 比赛页面上列出的直播流与录像视频 (VOD) 链接。官方转播频道与主播二路解说流在未开赛前即可获取；全场比赛及单地图录像通常在比赛结束后更新收录。

## 函数签名

```python
series.vods(series_id: int) -> SeriesVods
```

通过柯里化链式访问：

```python
vlrdevapi.series(series_id).vods() -> SeriesVods
```

## 示例

### 查看当前比赛的直播频道

```python
import vlrdevapi

vod_data = vlrdevapi.series.vods(series_id=670471)
print(f"可用直播频道 ({len(vod_data.streams)}):")
for s in vod_data.streams[:3]:
    print(f"  [{s.platform.upper()}] {s.channel} ({s.country_code}): {s.url}")
```

### 获取各小局回放录像

```python
import vlrdevapi

vod_data = vlrdevapi.series.vods(series_id=670471)
print(f"回放录像 ({len(vod_data.vods)}):")
for v in vod_data.vods[:3]:
    print(f"  {v.label}: {v.url}")
```

### 柯里化链式访问

```python
import vlrdevapi

series = vlrdevapi.series(670471)
vod_data = series.vods()
for v in vod_data.vods[:3]:
    print(f"{v.label} -> {v.url}")
```
