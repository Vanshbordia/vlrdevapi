---
title: Rendimiento de la Serie (Series Performance)
description: "Obtén datos avanzados de rendimiento: matrices de bajas (todas las bajas, first kills, bajas de Operator) y estadísticas de multikills y clutches."
---

`series.performance(series_id, game_id)` devuelve datos analíticos avanzados de rendimiento para una partida, incluyendo matrices completas de enfrentamientos individuales y estadísticas detalladas por jugador.

## Firma

```python
series.performance(
    series_id: int,
    game_id: int | str = "all",
) -> PerformanceData
```

Con acceso curried:

```python
vlrdevapi.series(series_id).performance(game_id: int | str = "all") -> PerformanceData
```

## Ejemplos

### Matriz de bajas

```python
import vlrdevapi

perf = vlrdevapi.series.performance(series_id=670471, game_id=1)
if perf.all_kills_matrix.entries:
    for entry in perf.all_kills_matrix.entries[:5]:
        print(f"{entry.killer} ({entry.killer_team}) eliminó a {entry.victim} ({entry.victim_team})")
```

### Acceso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
perf = series.performance(game_id=1)
for player in perf.adv_stats[:3]:
    print(f"{player.name} - 3K: {player.three_k} | 4K: {player.four_k} | Ace: {player.five_k}")
