title: 比赛对决与高级统计 (Series Performance)
description: "获取系列赛的高阶竞技表现数据：击杀对决矩阵（全击杀、首杀、大狙击杀）及多杀、残局 (Clutch) 统计。"
---

`series.performance(series_id, game_id)` 返回系列赛指定地图或全场汇总的高级竞技表现数据，涵盖详尽的选手对决击杀矩阵与关键局统计。

## 函数签名

```python
series.performance(
    series_id: int,
    game_id: int | str = "all",
) -> PerformanceData
```

通过柯里化链式访问：

```python
vlrdevapi.series(series_id).performance(game_id: int | str = "all") -> PerformanceData
```

## 示例

### 查看选手击杀矩阵

```python
import vlrdevapi

perf = vlrdevapi.series.performance(series_id=670471, game_id=1)
if perf.all_kills_matrix.entries:
    for entry in perf.all_kills_matrix.entries[:5]:
        print(f"{entry.killer} ({entry.killer_team}) 击杀 {entry.victim} ({entry.victim_team})")
```

### 柯里化链式访问

```python
import vlrdevapi

series = vlrdevapi.series(670471)
perf = series.performance(game_id=1)
for p in perf.adv_stats[:3]:
    print(f"{p.name} - 3K: {p.three_k} | 4K: {p.four_k} | Ace: {p.five_k}")
