`series.replay(series_id, game_id)` 返回系列赛指定小局地图每一回合的击杀日志时间线（对应 vlr.gg 上的 logs 面板）。

## 函数签名

```python
series.replay(
    series_id: int,
    game_id: int,
) -> ReplayData
```

通过柯里化链式访问：

```python
vlrdevapi.series(series_id).replay(game_id: int) -> ReplayData
```

## 示例

### 查看第 1 回合击杀日志流水

```python
import vlrdevapi

replay = vlrdevapi.series.replay(series_id=754737, game_id=283288)
print(f"{replay.team1} 对阵 {replay.team2}（共 {replay.num_rounds} 回合）")

for ev in replay.round(1).events:
    who = ev.actor.name if ev.actor else "-"
    print(f"{ev.seq}. {ev.seconds}秒 {ev.type.full_name}: {who}", end="")
    if ev.cause:
        print(f" ({ev.cause})", end="")
    if ev.victim:
        print(f" -> {ev.victim.name}", end="")
    print()
```

### 追踪爆弹安放与引爆事件

```python
import vlrdevapi
from vlrdevapi._series.replay.models import ReplayEventType

replay = vlrdevapi.series.replay(series_id=754737, game_id=283288)

for ev in replay.round(14).events:
    if ev.type in (ReplayEventType.PLANT, ReplayEventType.DEFUSE, ReplayEventType.BOOM):
        print(f"{ev.clock or '-'} {ev.type.full_name} 发生在 {ev.site} 包点，坐标 ({ev.pos_x}, {ev.pos_y})")
```

### 柯里化链式访问

```python
import vlrdevapi

series = vlrdevapi.series(754737)
replay = series.replay(game_id=283288)
round_1 = replay.round(1)
for ld in round_1.loadouts[:4]:
    print(f"{ld.name} ({ld.agent}): {ld.weapon} + {ld.armor} (花费 ${ld.spent})")
```
