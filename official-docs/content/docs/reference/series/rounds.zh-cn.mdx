---
title: 比赛回合战况 (Series Rounds)
description: "获取系列赛中指定地图的逐回合对战记录：回合获胜方、胜利方式、攻防阵营以及各队经济投入。"
---

`series.rounds(series_id, game_id)` 返回系列赛中单张小局地图的逐回合比赛记录，并直接关联了来自 vlr.gg 经济面板的资金、支出与买枪等级数据。

## 函数签名

```python
series.rounds(
    series_id: int,
    game_id: int,
) -> RoundsData
```

通过柯里化链式访问：

```python
vlrdevapi.series(series_id).rounds(game_id: int) -> RoundsData
```

## 示例

### 查看逐回合战报

```python
import vlrdevapi

rounds_data = vlrdevapi.series.rounds(series_id=670471, game_id=1)
print(f"比赛: {rounds_data.team1} vs {rounds_data.team2}")
for r in rounds_data.rounds[:5]:
    print(f"第 {r.round_number:2d} 回合: 比分 {r.team1_score}-{r.team2_score} | 获胜: {r.winner_team_name} ({r.win_type.full_name})")
```

### 柯里化链式访问

```python
import vlrdevapi

series = vlrdevapi.series(670471)
rounds_data = series.rounds(game_id=1)
defuses = [r for r in rounds_data.rounds if r.win_type == "defuse"]
print(f"拆包获胜的回合数: {len(defuses)}")
```
