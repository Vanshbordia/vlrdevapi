---
title: Series Streams & VODs
description: Fetch live/watch-party streams and VOD/video links for a match - Twitch, YouTube, Kick, regional platforms, and per-map videos.
---

`series.vods(series_id)` returns the streams and VOD (Video on Demand) links shown on a match page. Live broadcasts and watch parties are available even for upcoming matches; full-match and per-map videos are available after the match.

## Signature

```python
series.vods(series_id: int) -> SeriesVods
```

With curried access:

```python
vlrdevapi.series(series_id).vods() -> SeriesVods
```

## Examples

### List official streams and watch parties

Filter by `stream_type` to show only official broadcasts or include co-streams.

```python
import vlrdevapi

media = vlrdevapi.series.vods(series_id=754737)

for stream in media.streams:
    if stream.stream_type == "broadcast":
        print(f"[{stream.platform}] {stream.channel}: {stream.url}")
```

### Filter by platform and country

`country_code` is useful when a match has regional broadcasts on many platforms.

```python
import vlrdevapi

media = vlrdevapi.series.vods(series_id=777944)

for stream in media.streams:
    if stream.country_code == "cn":
        print(f"{stream.platform}: {stream.channel} ({stream.url})")
```

### List all VODs

Each VOD entry has a label, platform, and optional map number and start offset.

```python
import vlrdevapi

media = vlrdevapi.series.vods(series_id=542272)

for vod in media.vods:
    map_label = f"Map {vod.map_number}" if vod.map_number else "Full match"
    print(f"{map_label}: {vod.label} [{vod.platform}] {vod.url}")
```

### Split full-match and per-map VODs

```python
import vlrdevapi

media = vlrdevapi.series.vods(series_id=542272)

full_match = [vod for vod in media.vods if vod.map_number is None]
map_vods = [vod for vod in media.vods if vod.map_number is not None]

print(f"Full match: {full_match[0].url if full_match else 'not available'}")
for vod in map_vods:
    print(f"Map {vod.map_number} ({vod.label}): {vod.url}")
```

### Curried access

Use the curried pattern to access streams and VODs without passing the series ID repeatedly.

```python
import vlrdevapi

series = vlrdevapi.series(754737)
media = series.vods()

print(f"{len(media.streams)} streams, {len(media.vods)} VODs")
for stream in media.streams:
    print(f"[{stream.stream_type}] {stream.channel} - {stream.url}")
```
