---
title: Transmissões e VODs da Série (Series Streams & VODs)
description: "Obtenha links de transmissões ao vivo, watch parties e vídeos sob demanda (VODs) de uma partida - Twitch, YouTube, Kick e plataformas regionais."
---

`series.vods(series_id)` retorna as transmissões e links de VODs (Vídeo sob Demanda) exibidos na página da partida no vlr.gg. Transmissões oficiais e watch parties ficam disponíveis inclusive para partidas futuras; os vídeos da partida completa e por mapa são indexados após a conclusão do confronto.

## Assinatura

```python
series.vods(series_id: int) -> SeriesVods
```

Com acesso curried:

```python
vlrdevapi.series(series_id).vods() -> SeriesVods
```

## Exemplos

### Listar transmissões ao vivo

```python
import vlrdevapi

vod_data = vlrdevapi.series.vods(series_id=670471)
print(f"Transmissões disponíveis ({len(vod_data.streams)}):")
for s in vod_data.streams[:3]:
    print(f"  [{s.platform.upper()}] {s.channel} ({s.country_code}): {s.url}")
```

### Obter links de VODs da partida

```python
import vlrdevapi

vod_data = vlrdevapi.series.vods(series_id=670471)
print(f"VODs encontrados ({len(vod_data.vods)}):")
for v in vod_data.vods[:3]:
    print(f"  {v.label}: {v.url}")
```

### Acesso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
vod_data = series.vods()
for v in vod_data.vods[:3]:
    print(f"{v.label} -> {v.url}")
```
