---
title: Rondas de la Serie (Series Rounds)
description: "Obtén los datos ronda a ronda de un mapa específico de la serie: ganador, tipo de victoria, bando y economía por ronda."
---

`series.rounds(series_id, game_id)` devuelve el desglose ronda a ronda de un mapa concreto dentro de la serie, unificando los datos económicos (banco, gasto y tipo de compra) procedentes de la pestaña de economía de vlr.gg.

## Firma

```python
series.rounds(
    series_id: int,
    game_id: int,
) -> RoundsData
```

Con acceso curried:

```python
vlrdevapi.series(series_id).rounds(game_id: int) -> RoundsData
```

## Ejemplos

### Recorrer las rondas de la partida

```python
import vlrdevapi

rounds_data = vlrdevapi.series.rounds(series_id=670471, game_id=1)
print(f"Partida: {rounds_data.team1} vs {rounds_data.team2}")
for r in rounds_data.rounds[:5]:
    print(f"Ronda {r.round_number:2d}: {r.team1_score}-{r.team2_score} | Vencedor: {r.winner_team_name} ({r.win_type.full_name})")
```

### Acceso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
rounds_data = series.rounds(game_id=1)
defuse_wins = [r for r in rounds_data.rounds if r.win_type == "defuse"]
print(f"Rondas ganadas desactivando la Spike: {len(defuse_wins)}")
```
