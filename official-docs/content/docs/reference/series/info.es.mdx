---
title: Información de la Serie (Series Info)
description: "Obtén los datos generales del encuentro: equipos, marcadores, detalles del torneo, enfrentamientos directos, vetos de mapas y desglose por mapa."
---

`series.info(series_id)` devuelve la información general de una serie o partido en vlr.gg, incluidos detalles de los equipos, tanteador general, contexto del torneo, historial cara a cara, fase de veto y mapas disputados.

## Firma

```python
series.info(series_id: int) -> SeriesInfo
```

Con acceso curried:

```python
vlrdevapi.series(series_id).info() -> SeriesInfo
```

## Ejemplos

### Resumen del partido

```python
import vlrdevapi

info = vlrdevapi.series.info(series_id=670471)
print(f"{info.team1.name} {info.score1} - {info.score2} {info.team2.name}")
print(f"Torneo: {info.event_name} ({info.stage})")
print(f"Estado: {info.status}")
for g in info.games:
    if g.played:
        print(f"  {g.map_name}: {g.team1_score} - {g.team2_score}")
```

### Acceso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
info = series.info()
print(f"Vetos del encuentro ({len(info.veto)}):")
for v in info.veto:
    print(f"  {v.team} {v.veto_type} {v.map_name}")
```
