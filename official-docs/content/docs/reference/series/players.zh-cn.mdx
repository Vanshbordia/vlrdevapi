`series.players(series_id, game_id)` 返回系列赛中单张指定地图，或全场所有地图累计的选手竞技统计数据。

## 函数签名

```python
series.players(
    series_id: int,
    game_id: int | str = "all",
) -> PlayersStats
```

通过柯里化链式访问：

```python
vlrdevapi.series(series_id).players(game_id: int | str = "all") -> PlayersStats
```

## 示例

### 查看全场总数据

```python
import vlrdevapi

stats = vlrdevapi.series.players(series_id=670471, game_id="all")
for p in stats.players[:5]:
    print(f"{p.player_name} ({p.team_name}): {p.kills}/{p.deaths}/{p.assists} | ACS: {p.acs} | Rating: {p.rating}")
```

### 查看第 1 局数据

```python
import vlrdevapi

stats = vlrdevapi.series.players(series_id=670471, game_id=1)
print(f"地图 1: {stats.map_name}")
for p in stats.players:
    print(f"  {p.player_name} [{p.agent}]: {p.kills}击杀 / {p.deaths}阵亡 (KD {p.kd})")
```

### 柯里化链式访问

```python
import vlrdevapi

series = vlrdevapi.series(670471)
stats = series.players(game_id=1)
best_player = max(stats.players, key=lambda p: p.rating or 0)
print(f"第一图最佳选手: {best_player.player_name}，Rating 为 {best_player.rating}")
