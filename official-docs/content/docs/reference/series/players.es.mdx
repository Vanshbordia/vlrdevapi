---
title: Jugadores de la Serie (Series Players)
description: "Obtén estadísticas individuales de los jugadores en un encuentro: ACS, K/D, ADR, KAST y porcentaje de disparos a la cabeza."
---

`series.players(series_id, game_id)` devuelve las estadísticas detalladas de los jugadores para un mapa específico de la serie o agregadas a lo largo de todos los mapas.

## Firma

```python
series.players(
    series_id: int,
    game_id: int | str = "all",
) -> PlayersStats
```

Con acceso curried:

```python
vlrdevapi.series(series_id).players(game_id: int | str = "all") -> PlayersStats
```

## Ejemplos

### Estadísticas acumuladas de la serie completa

```python
import vlrdevapi

stats = vlrdevapi.series.players(series_id=670471, game_id="all")
for team in [stats.team1, stats.team2]:
    print(f"--- {team.team_name} ---")
    for p in team.players[:3]:
        s = p.stats.overall
        print(f"{p.name}: {s.kills}/{s.deaths}/{s.assists} | ACS: {s.acs} | Rating: {s.rating}")
```

### Estadísticas del Mapa 1

```python
import vlrdevapi

stats = vlrdevapi.series.players(series_id=670471, game_id=1)
print(f"Mapa 1: {stats.map_name}")
for team in [stats.team1, stats.team2]:
    for p in team.players[:2]:
        s = p.stats.overall
        agents = ", ".join(p.agents)
        diff = s.kd_diff if s.kd_diff is not None else 0
        print(f"  {p.name} [{agents}]: {s.kills}K / {s.deaths}D ({diff:+d})")
```

### Acceso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
stats = series.players(game_id=1)
all_players = stats.team1.players + stats.team2.players
best_player = max(all_players, key=lambda p: p.stats.overall.rating or 0)
print(f"MVP del Mapa 1: {best_player.name} con rating {best_player.stats.overall.rating}")
```
