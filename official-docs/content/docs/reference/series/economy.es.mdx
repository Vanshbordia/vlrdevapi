---
title: Economía de la Serie (Series Economy)
description: "Obtén los datos de economía ronda a ronda de un mapa: reservas bancarias, gastos, tipo de compra, ganador y matriz económica."
---

`series.economy(series_id, game_id)` devuelve los datos económicos de cada ronda para un mapa específico de la serie en vlr.gg.

## Firma

```python
series.economy(
    series_id: int,
    game_id: int,
) -> EconomyData
```

Con acceso curried:

```python
vlrdevapi.series(series_id).economy(game_id: int) -> EconomyData
```

## Ejemplos

### Análisis de la economía de las rondas

```python
import vlrdevapi

econ = vlrdevapi.series.economy(series_id=670471, game_id=1)
print(f"Economía: {econ.team1} vs {econ.team2}")
for r in econ.rounds[:5]:
    print(f"Ronda {r.round_number}: {econ.team1} ({r.buy_type_team1.value}, ${r.spent_team1}) vs {econ.team2} ({r.buy_type_team2.value}, ${r.spent_team2}) -> Ganador: {r.winner.name}")
```

### Acceso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
econ = series.economy(game_id=1)
if econ.pistol_team1:
    print(f"{econ.team1} rondas de pistolas: {econ.pistol_team1.won}/{econ.pistol_team1.total}")
