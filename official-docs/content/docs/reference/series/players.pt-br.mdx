---
title: Jogadores da Série (Series Players)
description: "Obtenha estatísticas individuais de jogadores por partida - ACS, K/D, ADR, KAST e porcentagem de headshots."
---

`series.players(series_id, game_id)` retorna estatísticas detalhadas de jogadores para um mapa específico dentro de uma série, ou agregadas para todos os mapas jogados.

## Assinatura

```python
series.players(
    series_id: int,
    game_id: int | str = "all",
) -> PlayersStats
```

Com acesso curried:

```python
vlrdevapi.series(series_id).players(game_id: int | str = "all") -> PlayersStats
```

## Exemplos

### Estatísticas consolidadas da série completa

```python
import vlrdevapi

stats = vlrdevapi.series.players(series_id=670471, game_id="all")
for team in [stats.team1, stats.team2]:
    print(f"--- {team.team_name} ---")
    for p in team.players[:3]:
        s = p.stats.overall
        print(f"{p.name}: {s.kills}/{s.deaths}/{s.assists} | ACS: {s.acs} | Rating: {s.rating}")
```

### Estatísticas do Mapa 1

```python
import vlrdevapi

stats = vlrdevapi.series.players(series_id=670471, game_id=1)
print(f"Mapa 1: {stats.map_name}")
for team in [stats.team1, stats.team2]:
    for p in team.players[:2]:
        s = p.stats.overall
        agents = ", ".join(p.agents)
        diff = s.kd_diff if s.kd_diff is not None else 0
        print(f"  {p.name} [{agents}]: {s.kills}K / {s.deaths}D ({diff:+d})")
```

### Acesso curried

```python
import vlrdevapi

series = vlrdevapi.series(670471)
stats = series.players(game_id=1)
all_players = stats.team1.players + stats.team2.players
best_player = max(all_players, key=lambda p: p.stats.overall.rating or 0)
print(f"MVP do Mapa 1: {best_player.name} com rating {best_player.stats.overall.rating}")
```
