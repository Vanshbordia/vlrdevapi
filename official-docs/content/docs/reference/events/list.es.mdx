title: Lista de Torneos (Event List)
description: Explora y busca torneos en vlr.gg con filtros por nivel (tier), región, estado y paginación.
---

`vlrdevapi.event.list()` devuelve listados paginados de eventos y torneos de vlr.gg con soporte para filtros de categoría competitiva, región, estado actual y paginación.

## Firma

```python
event.list(
    tier: TierType = "all",
    region: RegionType = "all",
    status: StatusType | None = None,
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> EventList
```

## Ejemplos de Código

```python
import vlrdevapi

events = vlrdevapi.event.list()

for event in events.events:
    dates = f"{event.start_date} - {event.end_date}" if event.start_date and event.end_date else "TBD"
    prize_text = event.prize.raw_text if event.prize else "N/A"
    print(f"[{event.status.upper()}] {event.name} ({dates})")
    print(f"Premios: {prize_text} | Región: {event.region}")
    print(f"ID: {event.id} -> {event.url}\n")
```
