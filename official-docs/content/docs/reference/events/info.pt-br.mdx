---
title: Informações do Evento (Event Info)
description: Obtenha metadados detalhados de um evento específico - nome, série, datas, premiação, localização física e regiões.
---

`event.info(event_id)` retorna metadados completos de um único evento ou torneio no vlr.gg.

## Assinatura

```python
event.info(event_id: int) -> EventInfo
```

## Parâmetros

<TypeTable type={{

    description: "Identificador numérico exclusivo do evento no vlr.gg.",
    type: "int",
    typeDescription: "Inteiro positivo",
    required: true,
  },
}} />

## Exemplos de Código

```python
import vlrdevapi

info = vlrdevapi.event(2765).info()
print(f"Evento: {info.name}")
if info.prize:
    print(f"Premiação: {info.prize.raw_text}")
if info.location:
    print(f"Local: {info.location.venue}, {info.location.country}")
print(f"Datas: {info.start_date} até {info.end_date}")
```
