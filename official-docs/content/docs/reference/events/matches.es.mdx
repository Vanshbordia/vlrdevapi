---
title: Partidos del Torneo (Event Matches)
description: Consulta los partidos de un torneo con filtrado por fase y estado, incluyendo enriquecimiento concurrente de IDs de equipo.
---

`event.matches(event_id)` devuelve la lista de partidos de un torneo con filtrado flexible por fase y estado. Los identificadores de equipo se completan de forma automática y en paralelo mediante consultas directas de series.

## Firma

```python
event.matches(
    event_id: int,
    stage_id: str | None = None,
    state: Literal["all", "completed", "live", "upcoming"] = "all",
) -> EventMatches
```

## Ejemplos de Código

```python
import vlrdevapi

# Obtener partidos finalizados de un torneo
matches = vlrdevapi.event(2765).matches(state="completed")

for m in matches.matches[:5]:
    t1, t2 = m.teams[0], m.teams[1]
    s1 = t1.score if t1.score is not None else 0
    s2 = t2.score if t2.score is not None else 0
    print(f"{t1.name} [{s1} - {s2}] {t2.name} | {m.stage} - {m.phase}")
```
