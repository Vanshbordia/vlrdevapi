---
title: Times do Evento (Event Teams)
description: Obtenha as equipes participantes de um evento, agrupadas por etapa com requisições paralelas para torneios multi-etapas.
---

`event.teams(event_id)` retorna as equipes que disputam o evento, agrupadas por etapa. Quando o evento possui múltiplas etapas, as páginas de times são consultadas em paralelo (até 5 requisições concorrentes) para máxima velocidade.

## Assinatura

```python
event.teams(
    event_id: int,
    stage: str | None = None,
) -> EventTeams
```

## Exemplos de Código

```python
import vlrdevapi

event_teams = vlrdevapi.event(2765).teams()

for stage in event_teams.stages:
    print(f"\nEtapa: {stage.stage_name} ({len(stage.teams)} times)")
    for team in stage.teams:
        print(f"  - {team.name} ({team.tag or 'Sem Tag'}) - País: {team.country}")
```
