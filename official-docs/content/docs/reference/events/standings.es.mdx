---
title: Clasificación del Torneo (Event Standings)
description: Consulta la tabla de posiciones y grupos de un torneo, agrupada por fase con descargas concurrentes.
---

`event.standings(event_id)` devuelve la clasificación y tablas de grupos de un torneo, organizadas por fase. Los torneos con múltiples fases se obtienen en paralelo (hasta 5 peticiones concurrentes) para minimizar el tiempo de espera.

## Firma

```python
event.standings(
    event_id: int,
    stage: str | None = None,
) -> EventStandings
```

## Ejemplos de Código

```python
import vlrdevapi

standings = vlrdevapi.event(2765).standings()

for stage in standings.stages:
    print(f"\n--- {stage.stage_name} ---")
    for entry in stage.standings:
        print(f"#{entry.rank} {entry.team.name:20s} | Series: {entry.series_record} | Mapas: {entry.map_record}")
```
