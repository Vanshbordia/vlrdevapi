---
title: 赛事阶段积分榜 (Event Standings)
description: 获取赛事的各赛段分组积分榜与晋级排名，多赛段自动并发获取，支持可选赛段过滤。
---

`event.standings(event_id)` 返回赛事的分组积分与名次排行，按赛段自动分类。针对多赛段锦标赛支持并行网络抓取（最高 5 个并发），以提供极致的响应性能。

## 方法签名

```python
event.standings(
    event_id: int,
    stage: str | None = None,
) -> EventStandings
```

## 代码示例

```python
import vlrdevapi

standings = vlrdevapi.event(2765).standings()

for stage in standings:
    print(f"\n--- {stage.stage_name} ---")
    for entry in stage.standings[:3]:
        prize = f"{entry.prize_currency}{entry.prize_money:,}" if entry.prize_money else "无奖金"
        print(f"{entry.place}: {entry.team.name} | {prize}")
```
