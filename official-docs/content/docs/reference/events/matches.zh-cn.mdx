---
title: 赛事赛程与对阵 (Event Matches)
description: 按赛段和对局状态筛选赛事包含的比赛，支持在底层并行补全参赛战队的唯一数值 ID。
---

`event.matches(event_id)` 返回赛事内部的赛程场次，支持按赛段和对局状态（未开始、直播中、已完赛）灵活筛选。各对阵队伍的 ID 将通过后台线程池在抓取系列赛概览时自动并行填充。

## 方法签名

```python
event.matches(
    event_id: int,
    stage_id: str | None = None,
    state: Literal["all", "completed", "live", "upcoming"] = "all",
) -> EventMatches
```

## 代码示例

```python
import vlrdevapi

# 获取指定赛事中已完赛的赛果
matches = vlrdevapi.event(2765).matches(state="completed")

for m in matches.matches[:5]:
    t1 = m.team1.name if m.team1 else "待定"
    t2 = m.team2.name if m.team2 else "待定"
    s1 = m.score1 if m.score1 is not None else 0
    s2 = m.score2 if m.score2 is not None else 0
    print(f"{t1} [{s1} - {s2}] {t2} | {m.round_info}")
```
