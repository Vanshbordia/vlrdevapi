---
title: Partidas do Evento (Event Matches)
description: Consulte as partidas de um evento com filtros por etapa e status, incluindo enriquecimento concorrente dos IDs de times.
---

`event.matches(event_id)` retorna as partidas de um torneio com filtragem flexível por etapa e status de jogo. Os IDs das equipes são enriquecidos em paralelo através de consultas rápidas das séries.

## Assinatura

```python
event.matches(
    event_id: int,
    stage_id: str | None = None,
    state: Literal["all", "completed", "live", "upcoming"] = "all",
) -> EventMatches
```

## Exemplos de Código

```python
import vlrdevapi

# Obter partidas finalizadas de um evento
matches = vlrdevapi.event(2765).matches(state="completed")

for m in matches.matches[:5]:
    t1 = m.team1.name if m.team1 else "TBD"
    t2 = m.team2.name if m.team2 else "TBD"
    s1 = m.score1 if m.score1 is not None else 0
    s2 = m.score2 if m.score2 is not None else 0
    print(f"{t1} [{s1} - {s2}] {t2} | {m.round_info}")
```
