---
title: 参赛战队名单 (Event Teams)
description: 获取赛事的参赛战队名单，支持按赛段归类展示，针对多赛段锦标赛支持并行网络抓取。
---

`event.teams(event_id)` 返回参与该赛事的全部参赛战队，并按赛段（如小组赛、淘汰赛）自动分组。当赛事包含多个赛段时，数据会通过线程池并行请求（最高 5 个并发），以实现极致的抓取效率。

## 方法签名

```python
event.teams(
    event_id: int,
    stage: str | None = None,
) -> EventTeams
```

## 代码示例

```python
import vlrdevapi

event_teams = vlrdevapi.event(2765).teams()

for stage in event_teams:
    print(f"\n赛段: {stage.stage_name} (包含 {len(stage.teams)} 支队伍)")
    for team in stage.teams[:3]:
        print(f"  - {team.name} (ID: {team.id})")
```
