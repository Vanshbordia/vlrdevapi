---
title: 赛事详情 (Event Info)
description: 获取特定赛事的完整元数据 — 包含赛事名称、所属系列赛、赛期起止日期、奖金总额、举办城市与赛区。
---

`event.info(event_id)` 返回 vlr.gg 上单场锦标赛的详尽综合元数据。

## 方法签名

```python
event.info(event_id: int) -> EventInfo
```

## 代码示例

```python
import vlrdevapi

info = vlrdevapi.event(2765).info()
print(f"赛事: {info.name}")
if info.prize:
    print(f"奖金: {info.prize.raw_text}")
if info.location:
    print(f"举办场馆: {info.location.venue}, {info.location.country}")
print(f"赛期: {info.start_date} 至 {info.end_date}")
```
