---
title: 赛事列表 (Event List)
description: 在 vlr.gg 上按赛事级别、赛区、进行状态与分页参数浏览并检索锦标赛列表。
---

`vlrdevapi.event.list()` 返回来自 vlr.gg 的分页赛事列表，支持按赛事竞技级别 (tier)、地理赛区、进行状态及自动跨页查询。

## 方法签名

```python
event.list(
    tier: TierType = "all",
    region: RegionType = "all",
    status: StatusType | None = None,
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> EventList
```

## 代码示例

```python
import vlrdevapi

# 查询 VCT 美洲赛区目前正在进行的全部赛事
ongoing = vlrdevapi.event.list(
    tier="vct",
    region="americas",
    status="ongoing",
)

for event in ongoing.events:
    print(f"[{event.status.upper()}] {event.name} ({event.dates})")
    print(f"奖金: {event.prize} | 赛区: {event.region}")
    print(f"ID: {event.id} -> https://vlr.gg{event.url}\n")
```
