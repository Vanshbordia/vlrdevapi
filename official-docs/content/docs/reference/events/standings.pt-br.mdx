---
title: Classificação do Evento (Event Standings)
description: Obtenha a tabela de classificação e pontuação de um evento, agrupada por etapa com suporte a requisições paralelas.
---

`event.standings(event_id)` retorna a classificação e tabelas de grupos de um evento, agrupadas por etapa. Eventos com múltiplas etapas são consultados em paralelo (até 5 requisições concorrentes) para garantir alta performance.

## Assinatura

```python
event.standings(
    event_id: int,
    stage: str | None = None,
) -> EventStandings
```

## Retorno - `EventStandings`

`EventStandings` encapsula uma lista de instâncias de `EventStageStandings` e suporta `__len__`, `__iter__` e `__getitem__`.

## Exemplos de Código

```python
import vlrdevapi

standings = vlrdevapi.event(2765).standings()

for stage in standings:
    print(f"\n--- {stage.stage_name} ---")
    for entry in stage.standings[:3]:
        prize = f"{entry.prize_currency}{entry.prize_money:,}" if entry.prize_money else "Sem premiação"
        print(f"{entry.place}: {entry.team.name} | {prize}")
```
