---
title: Información del Torneo (Event Info)
description: "Consulta metadados detallados de un torneo específico: nombre, serie, fechas, bolsa de premios, sede física y regiones."
---

`event.info(event_id)` devuelve metadados completos y detallados de un torneo en vlr.gg.

## Firma

```python
event.info(event_id: int) -> EventInfo
```

## Parámetros

<TypeTable type={{

    required: true,
  },
}} />

## Ejemplos de Código

```python
import vlrdevapi

info = vlrdevapi.event(2765).info()
print(f"Torneo: {info.name}")
if info.prize:
    print(f"Bolsa de premios: {info.prize.raw_text}")
if info.location:
    print(f"Sede: {info.location.venue}, {info.location.country}")
print(f"Fechas: {info.start_date} al {info.end_date}")
```
