title: Lista de Eventos (Event List)
description: Explore e busque eventos no vlr.gg com filtros por nível (tier), região, status e paginação.
---

`vlrdevapi.event.list()` retorna listagens paginadas de eventos e torneios do vlr.gg com suporte a filtros de nível competitivo, região, status e paginação completa.

## Assinatura

```python
event.list(
    tier: TierType = "all",
    region: RegionType = "all",
    status: StatusType | None = None,
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> EventList
```

## Exemplos de Código

```python
import vlrdevapi

# Buscar torneios em andamento no VCT Americas
ongoing = vlrdevapi.event.list(
    tier="vct",
    region="americas",
    status="ongoing",
)

for event in ongoing.events:
    print(f"[{event.status.upper()}] {event.name} ({event.dates})")
    print(f"Premiação: {event.prize} | Região: {event.region}")
    print(f"ID: {event.id} -> https://vlr.gg{event.url}\n")
```
