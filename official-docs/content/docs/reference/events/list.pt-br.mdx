title: Lista de Eventos (Event List)
description: Explore e busque eventos no vlr.gg com filtros por nível (tier), região, status e paginação.
---

`vlrdevapi.event.list()` retorna listagens paginadas de eventos e torneios do vlr.gg com suporte a filtros de nível competitivo, região, status e paginação completa.

## Assinatura

```python
event.list(
    tier: TierType = "all",
    region: RegionType = "all",
    status: StatusType | None = None,
    page: int = 1,
    max_page: int = 0,
    return_all: bool = False,
) -> EventList
```

## Exemplos de Código

```python
import vlrdevapi

events = vlrdevapi.event.list()

for event in events.events:
    dates = f"{event.start_date} - {event.end_date}" if event.start_date and event.end_date else "TBD"
    prize_text = event.prize.raw_text if event.prize else "N/A"
    print(f"[{event.status.upper()}] {event.name} ({dates})")
    print(f"Premiação: {prize_text} | Região: {event.region}")
    print(f"ID: {event.id} -> {event.url}\n")
```
