---
title: Equipos del Torneo (Event Teams)
description: Obtén los equipos participantes de un torneo agrupados por fase, con descargas concurrentes en torneos multifase.
---

`event.teams(event_id)` devuelve las escuadras que compiten en el torneo, agrupadas por fase. Cuando un evento cuenta con varias fases, los datos se descargan en paralelo (hasta 5 peticiones simultáneas) para acelerar la respuesta.

## Firma

```python
event.teams(
    event_id: int,
    stage: str | None = None,
) -> EventTeams
```

## Ejemplos de Código

```python
import vlrdevapi

event_teams = vlrdevapi.event(2765).teams()

for stage in event_teams:
    print(f"\nFase: {stage.stage_name} ({len(stage.teams)} equipos)")
    for team in stage.teams[:3]:
        print(f"  - {team.name} (ID: {team.id})")
```
